# V0.4.2 展柜空间与物件机制返修

439336 / 0.4.1 的手机反馈否定了展柜穿遮、旧胶带碎块与铃的切图式动作。旧经济和存档框架可以继续使用；旧视觉框架缺少完整轮廓、空间和机构约束，不能再把“有动画”或工程绿灯当作动作正确。本轮只补齐这三个缺口，现代收据、细像素控件和首星其他内容保留。

## 新的视觉约束

- **房间空间**：柜体、内腔、门、托盘、铭牌、点击区域、完整机器人轮廓及脚印来自同一注册。通道留出96 world身体和左右各6余量。机器人136 world原尺度不缩小，不靠永远盖在柜前或把玻璃变透明掩盖穿模。
- **连续取放**：六次14秒服务，包含走近、开门、抬托、伸盘、双握、抬清、观察、放稳、回盘和关门。五片玻璃收入自己的罩顶，固定框不动；手和物件使用真实接触点，有限连杆不能任意伸长。未完成或未加载展品只观察，修好/重连/后台恢复不会在同一轮突然拿起来。
- **一条胶带**：独立新卷架、金属轴、前后轴承、纸卷和一条连续带材质。0／Ⅰ／Ⅱ共享固定出口与同一机构，不再拼旧收据纸块或拉伸整件截图。分拣机第三个旧截图桥调用同步退役；既有工程折扣与工时效果保留。
- **一个铃机构**：铜壳、底座和孔圈固定；帽和恒长杆沿原孔移动，螺纹在孔后。手接触→按压→触底声波→释放回弹→收工具来自同一2600ms时钟。原默认静音保留，响铃只跟随实际触底帧，后台不会补响。
- **真实装配尺寸**：PNG原坐标与384边长运行WebP明确转换，金属轴不能在压缩后变短。房间、近景、研究和六张新三态PNG使用同一物件机制。

详见[收藏室空间](MUSEUM_SPACE_REFACTOR.md)、[原实机反馈](USER_REVIEW_V041.md)、`src/fusion/curio-mechanism-model.ts`、`src/fusion/curio-mechanism-renderer.ts`。新源PNG和可重复导出脚本保留，批准概念图不当生产atlas使用。

## 验证方法

1. 真Canvas矩阵、源alpha、关节及腕点记录；四种已购柜级的全路径检查。模型dataset只保护时序与UI，不独立证明实际图像正确。
2. 正常流逝时间下比较完整互动后存档与合法自动探索结果，只排除存储写入revision；不能用未来冻结存档证明免费。
3. 新固定包分别录全基础、全Lv3和混合0/1/2/3柜级100秒；核对六柜完整服务、完整身体、托盘清沿和近侧遮挡。胶带0／Ⅰ／Ⅱ与铃各录两次完整互动，六件整理处理另有自然时间录像和费用账本。
4. 360×800、390×844、桌面、Chromium/WebKit、减少动态、后台、失败重连和旧27049档回归。实际物理手机、锁屏、低端WebView和发热仍由用户新码测试，不能以桌面仿真代替。

# 收藏室空间与取放样板

本文件记录正在内部审核的空间重构；不表示 TapTap 实机或美术验收已通过。不改货币、收费、收藏、已购柜级或存档。

## 同一空间注册

- 运行时唯一几何源：`src/render/museum-space.ts`；服务轨迹：`src/render/museum-service.ts`。
- 768×960 房间中，两排六柜中心为 `104/384/664`，行基准 `500/825`。实际柜宽172，内腔128×168，侧走道244/524，净宽108。
- 机器人保持136 world原尺度。走动收臂、重定透明cell原点；源alpha及真实绘制关节的两朝向101步态测试，使用96宽投影包络、80宽保守脚印，保留左右6world通道余量。脚印同时有前后范围，不只检查足点。
- 内腔加高12，给现代收据与归档支架抬托时留出真实头部空间；不压小纸张或裁切票头。铭牌在基座正面，不挂进走道。点击区来自当前已购柜级的同一几何。

## 14秒服务，六柜84秒

行走 → 观察并收拢展品活动 → 五片玻璃沿固定导轨套叠进罩顶 → 托盘抬升10并移出70 → 按物件固定部位的同侧双握点夹持 → 先抬清托盘，再横移，最后降至持位 → 观察 → 原路放稳并松手 → 托盘回位并落座 → 关门 → 返回。

玻璃套叠片高34/33/34/33/34，能够进入最小36高的原罩顶。近侧立柱、基座和导轨固定。新透明反射材质使用内置 imagegen 制作，原图、导出参数、SHA保留在 `assets/source/visual-renewal/museum/PANE_REGISTRATION.json`；静态材质已由根任务审核，实际房间仍需连续审查。

握点唯一表为 `src/fusion/curio-museum-handling.ts`。机器人不抓活动盖、铃帽或纸边；收据抓其完整归档支承，胶带与铃抓自身固定座。房间低托盘和柜内固定支承不作为藏品一起拿走。新胶带自带完整卷座，因此删除旧紫柱、横梁和穿过卷座的内环。

馆内两连杆有限长度49/48 local；默认星球和夜守rig不启用此选项。真实绘制测试检验连杆长度及两个手腕原点，不能依靠无限伸长接上目标。

## 遮挡

后罩/内腔、真实移动托盘及藏品、固定近侧柱/基座、移动玻璃、机器人身体与最终接触手分别绘制。柜后仍有正确遮挡；走道留出了完整身体宽度。服务时身体留在柜前，托盘穿过真实前平面后进入其前景深，不能按整张柜图一次排序。

托盘实体底沿按实际绘制的 `floor-1` 注册；软接触影不算实体。托盘跨越近沿前至少有2world垂直余量。藏品和整个移动支承分别做全路径检查。新玻璃故障继续由原资源失败/重试与独立工作台回退处理。

## 资格与后台

只有已解锁、材质就绪且物理完成的展品可拿取；其他情况观察。资格在一次visit起始行走段锁定。修补完成、资源恢复、抽屉返回不能在同一次visit中突然开始满幅拿取。隐藏不抹去既有资格；首次或跨后台回到新visit中段时先观察，等下一完整visit。此门控只属于视图，不写玩家存档。

## 审阅诊断

普通页面默认不显示几何线。给实际场景canvas设置 `dataset.spaceDebug='true'` 可显示实体占地、开口、身体/脚印、藏品与托盘包络和真实手位。每次真实绘制后写入：`spaceVersion/servicePhase/caseLevel/bodyClearance/handReach/doorLift/trayExtension/actorBounds/feetBounds/itemBounds/armDeployment/contact/handContacts/drawOrder`。非接触阶段的handContacts为空。

`tests/museum-space.test.ts` 覆盖四柜级六物全路径、有限可达、完整身体与脚印、门开合、物件与托盘清沿、连续性及资格恢复。`tests/museum-rig-envelope.test.ts` 实际记录源alpha、绘制矩阵、关节、真实手腕和托盘实体。可用 `MUSEUM_ENVELOPE_OUTPUT=实际PNG路径 npx vitest run tests/museum-rig-envelope.test.ts` 输出内部离屏包络示意；该图不是运行截图、录屏或手机测试。

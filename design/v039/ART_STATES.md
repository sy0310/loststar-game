## 注册与接触

胶带和铃均使用192×192归一画布。胶带原图192×169，比例1、偏移(0,11.5)；铃原图256×241，比例0.75、偏移(0,5.625)。材质层也为192×192。导出 alpha clip 的像素栅格采用胶带y12、铃y6，运行刚体以归一浮点变换为准，边界差异小于0.5纹理像素。

| 点 | 归一坐标 | 用途 |
| --- | --- | --- |
| 胶尾根部 | (67,140) | 原胶带结构受力和压顺 |
| 胶尾断头 | (44,155) | 断头复位接缝 |
| 胶尾粘纸团 | (38,150) | 镊尖夹持与去污遮罩 |
| 胶卷外壁粘附 | (151,118) | 固定卷壁清理；不能随胶尾旋转 |
| 铃锈壳 | (91,129)、(128,127) | 穹顶下沿擦拭 |
| 铃轴根 | (87,56) | 局部清理 |
| 铃顶杆 | (87,34) | 原顶杆释放及回弹 |
| 底座右固定件 | (112,169) | 一字刀工作点；使用原底座金属像素 |

**铃没有实体指示灯。** 最初以黑底 `view_image` 观察时，右丝带之间出现红色像素，误被当成红灯；像素复核发现原图(215,108)为RGBA(247,0,0,1)，周围alpha仅1～2。这是几乎完全透明的RGB残色，正常alpha合成后消失，不能据此制作灯或照亮丝带。已通知主线程及渲染代理撤除暗灯/亮灯层；结构修复只使用原顶杆与底座原金属固定件。

镊子与螺丝刀采用独立紧裁画布；`registration.json` 中的 `contact` 是工具前端，`pivot` 是实际持握位置，不能拿工具图片中心贴到接触点。镊子 `contact` 是两个尖端之间的夹持中心，因此该逻辑点允许透明；螺丝刀 `contact` 是实心一字刃前缘。建议工具全宽24世界像素，必要时按实际近景比例审查。

## 审计文件与边界

- `material-registration-audit.png`：首行原胶带/粘附胶带/原铃/锈蚀铃；次行透明工具及68px物件缩图。这是材质合成审计，不是运行截图。
- `material-native68-audit-4x.png`：先缩为68px，再最近邻放大4倍；用于发现“小图材质看不见”的问题。首版纤维v1过细，已保留而选用集中且更可辨的v2。
- `assets/runtime/v039/registration.json`：六张WebP的尺寸、真实alpha包络、源图SHA、裁切、注册、工具接触点与握点。原PNG不是sprite atlas，运行图层仍需实际渲染器接入验证。
- `scripts/export_v039_art_assets.mjs`：只裁切、最近邻缩放、真实alpha裁限、注册与lossless WebP导出。没有以程序几何图形补画材质。

主线程需要在真实工作台对照：发现／整理／完成三态，工具前端实际接触，清理沿路径发生，胶尾与固定卷壁不混动，铃扣/顶杆归位，最后再审核原展示柜内的同一物件。

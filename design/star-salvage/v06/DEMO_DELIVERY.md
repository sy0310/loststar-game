## 这版确实实现了什么

- 直接起飞，单指拖动/鼠标拖动/WASD，主炮自动射击。纵向滚动星空；三类普通敌人、一个精英，战斗掉经验、零件及少量奇物。
- 升级弹出**三选一**卡片，角色有基本主炮，局内可选追踪无人机、电弧核心与离子护盾，并逐级强化（最高三级）。
- 四个**实际伤害/保护逻辑**的联动，不只是标题：
  1. 主炮＋电弧：命中可触发下一目标的连锁电击（`雷光齐射`）。
  2. 无人机＋电弧：追踪弹命中后继续放电（`雷暴无人机`）。
  3. 离子护盾＋电弧：护盾实际抵消一次伤害，消耗护盾并放电伤害附近敌人（`放电反击`）。
  4. 主炮＋无人机：主炮标记目标、无人机追击同目标提高伤害（`协同锁定`）。
- 首轮约90秒会遇折返选择，玩家可以安全结算或继续深入，**不再按距离收返航燃料**。结束后保留少量**仅本Demo内部**的永久主炮/船体强化，支持马上再来一局。
- 所有美术是代码生成的临时像素图，**不是正式飞船/怪物资源**。没有接入原有B＋C货舱、四船、黑市、历史剧情或正式星域，也没有把任何旧款项迁移到新游戏。

## 已做的隔离 QA（不是正式手机签收）

- Chromium headless `set_content` 测试：360×800 / 390×844，两种布局的起飞、升级卡选择、无人机+电弧、阶段折返、结算、重开、暂停/继续全部通过；浏览器 `pageerror` 为0。
- 4项函数层联动效应的隔离浏览器实测（通过时间模拟/显式敌人夹具）：
  - 主炮+电弧：第二敌人的HP从120降为103（连锁命中）。
  - 无人机+电弧：第二敌人的HP从120降为78.7（追踪命中连锁）。
  - 主炮+无人机：对单目标连续命中后HP=73，存在标记额外伤害。
  - 护盾+电弧：护盾从1耗尽、船体仍100HP，邻近敌人的HP从120降为80。
- 加速时间模拟中，前约12／22／33秒可以连续触发升级（测试取样，不是用户实际秒数或稳定概率承诺）。
- QA利用本环境已安装系统Chromium；**未在当前环境验证WebKit/Safari、真实Touch WebView、锁屏/真实帧率/发热、90秒自然通关、玩家是否主动二刷**。这属于必须找实际试玩者回答的体验问题。

## 使用方法

直接从 GitHub 查看`prototypes/salvage-continuous-flight-spike/index.html`。本机 Codex 已有仓库时可：

```bash
cd prototypes/salvage-continuous-flight-spike
python3 -m http.server 4396
# 新终端，Mac上执行：
open http://127.0.0.1:4396/
```

也可把上述`index.html`下载保存后双击打开浏览器运行，全部CSS/JS内嵌，无需外链资源。独立原型存储键`loststar.flight-spike.prototype.v01`，**不读取、不写入**原正式试玩存储；不占用原Mac4283端口。

## 建议玩家试玩验收的4个问题

1. 0–10秒能否毫无说明学会操作、是否感到有手感？
2. 第一二次升级时是否看得见武器变化、联动效果能否比文字提示更有说服力？
3. 约90秒的精英与折返是否让人愿意“再往前”？
4. 结算后是否真的想按`再飞一次`？至少比原v0.5.1更有冲动吗？

**只有这条原型获得玩家确认，才讨论让它成为真正v0.6主循环，并单独设计如何安全迁移四船/油箱与旧货舱/已购权益/黑市经济**。这个Demo没有授权重构、正式发布、合并或替换原试玩。

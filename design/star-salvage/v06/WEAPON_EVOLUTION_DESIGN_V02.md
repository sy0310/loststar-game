# 《失物号 · 星海突进》武器与进化系统设计稿 v0.2

> 状态：**玩法设计候选，未开发**。现有能玩的独立 Demo 为 `prototypes/salvage-continuous-flight-spike/index.html`（原型 0.1）；正式《失物号：星海拾荒》v0.5.1、TapTap开发自测469033、旧存档保持不变。
>
> 目标：学习《Survivor.io》“主动武器＋被动技能＋满级进化”“两种主动武器融合”等成熟机制，但保持《失物号》一指拖动、自动攻击、2～3分钟就能形成成就感的节奏，避免重做其复杂养成。

## 0. 目前到底做了多少？

原型 **4类可升级装备**：双联脉冲主炮（主攻，初始装备）、追踪无人机（副攻）、电弧核心（范围伤害）、离子护盾（防御）；每种最多Lv3。另有4个“拿到两件就生效”的即时联动：雷光齐射、雷暴无人机、放电反击、协同锁定。

**尚未实现：独立的被动辅助技能栏、五级/三级满级后的EVO转变、满级双主动融合、完整的Build推荐与进化宝箱。** 不得把当前四个联动称作已经做好的《Survivor.io》式进化。

## 1. 借鉴的玩法原则（不复制内容）

- 《Survivor.io》主动技能负责攻击或防御，被动辅助技能提升攻速、伤害、范围、生存等；通常武器达到5星且获得对应被动技能，才有机会进化成威力和机制不同的EVO。参见：[SurvivorIO Wiki Skills](https://survivorio.fandom.com/wiki/Skills)、[Apple App Store编辑内容](https://apps.apple.com/ca/iphone/story/id1641743438)。
- 双武器真正融合：如游戏中的两种无人机最终合成一个更强单位，并释放武器槽。我们借鉴“**双满级融合、给玩家一个大反馈、释放一个槽位**”这个机制，不复刻它的物品、名称、美术和具体技能数值。
- 《失物号》每趟更短，所以建议**主动武器最高3星、被动辅助最高2星**。这与《Survivor.io》的5星不是同一系统；无须为了模仿而拖长升级过程。

## 2. 原型的容量与分类

- 同时上阵：**最多4个主动槽（初始主炮占1槽）＋3个被动辅助槽**。界面为“主动4格 / 被动3格”两行短图标。
- 设计池：**6种主动、6种被动、6条主动＋被动EVO、2条主动＋主动融合**，共20种基础/进阶内容条目（其中进阶不是额外占栏装备）。
- 武器种类包括直射、追踪、连锁、爆炸、旋转防卫、护盾；不是6种只换色的主炮。
- 已拥有的主动或被动可以继续升级。升级选项来自合法候选池，始终优先兼顾“一个当前Build补强、一条接近进化的路线、一项不同打法”；三选一需真实可点击，不强迫“只有一种”合理路线。

## 3. 六种主动装备

| ID | 装备名 | 分类 | Lv1实际行为 | 2～3星真正变化 | 核心作用 |
|---|---|---|---|---|---|
| A1 | 脉冲主炮 | **主攻·直线** | 自动瞄准前方，单发脉冲 | 双联、穿透前期薄敌 | 单体稳定输出、入门默认 |
| A2 | 追踪无人机 | **副攻·追踪** | 发射自动跟踪弹 | 追加副机、缩短锁定间隔 | 追杀漏网目标，Boss补刀 |
| A3 | 电弧线圈 | **副攻·连锁** | 攻击附近两个目标 | 连锁数量和触发频率提高 | 多敌清场，联动中心 |
| A4 | 震荡导弹 | **主攻·范围** | 低频弹头爆炸并产生小范围伤害 | 分裂/更大爆炸面积 | 打密集敌群和装甲目标 |
| A5 | 旋刃护卫机 | **辅助攻击·环绕** | 一枚短距环绕刃伤害靠近敌人 | 双刃/回旋阻挡弹体 | 近防与保护拾取路线 |
| A6 | 离子护盾 | **防御·主动装置** | 自动吸收一次碰撞，过一段时间恢复 | 充能更快、范围略扩大 | 保命、容错、触发反击 |

注：具体伤害、CD、子弹数和碰撞体积是未来**可跑模拟的数值配置**，本稿只定效果类型和玩法目的。

## 4. 六种被动辅助（本身不自动开火）

| ID | 名称 | 单独效果 | 推荐对应EVO |
|---|---|---|---|
| P1 | 聚能透镜 | 增加子弹贯穿/射程表现 | 主炮进化 |
| P2 | 锁定芯片 | 缩短目标锁定时间，标记精英 | 无人机进化 |
| P3 | 超导电容 | 提高连锁触发稳定性/范围 | 电弧进化 |
| P4 | 冷却矩阵 | 缩短主动武器开火冷却 | 导弹进化 |
| P5 | 回收磁场 | 扩大战利品吸附范围（不自动得奖励） | 旋刃进化 |
| P6 | 反应装甲 | 减少碰撞伤害/加快护盾循环 | 护盾进化 |

## 5. 两条进化路线，不要混淆

### 5.1 主动满级＋对应被动 → EVO（6条）

**条件：**某主动到Lv3，持有对应被动至少Lv1，下一次精英宝箱/升级特殊卡出现“进化”选项；点击才转化，玩家保留被动辅助。视觉与攻击模式必须明显改变。

| 组合 | EVO名称 | 真正改变的机制 | 第一眼能看出的差别 |
|---|---|---|---|
| A1主炮Lv3＋P1透镜 | **贯星轨炮** | 主炮汇聚成宽幅贯穿束，穿透多个敌人 | 一道长距离穿透光束 |
| A2无人机Lv3＋P2锁定 | **猎手蜂群** | 多无人机集中攻击被标记的强敌 | 多个小机围绕目标追击 |
| A3电弧Lv3＋P3电容 | **星链雷网** | 闪电同时跨越更多目标，短暂打断 | 多条清晰电链覆盖一群敌人 |
| A4导弹Lv3＋P4冷却 | **彗星弹幕** | 由单枚爆炸变为几枚连续小范围落点 | 连续爆炸弧线 |
| A5旋刃Lv3＋P5磁场 | **磁旋收割阵** | 旋刃吸引近处掉落并切割临近小怪 | 明显转动的外围圆环 |
| A6护盾Lv3＋P6装甲 | **反应壁垒** | 抵挡后向四周发出短脉冲反击 | 光圈扩散＋撞击停顿 |

### 5.2 两个主动都满级 → 双武器融合（2条）

**条件：**两件主动都到Lv3，下一次精英宝箱/合成卡片给出一次“合体确认”；成功后**两个主动槽合并成一个升级后武器槽**，释放一个空位。两者任一已走过单武器EVO时不允许二次合体。玩家可以拒绝、保留两件原武器。

| 双满级融合 | 融合武器 | 实际效果与槽位 |
|---|---|---|
| 追踪无人机Lv3＋电弧线圈Lv3 | **雷暴蜂群** | 无人机命中电击在敌人间跳跃；两个主动变一个，空出一个槽 |
| 震荡导弹Lv3＋旋刃护卫机Lv3 | **爆裂刃环** | 环绕刃接近敌群时触发小爆炸并继续旋转；两个主动变一个，空出一个槽 |

### 5.3 早期软联动（不是满级进化）

为保证第一分钟就有爽感，仍保留已有4种：主炮＋电弧的雷光齐射、无人机＋电弧的雷暴无人机**前期版**、护盾＋电弧的放电反击、主炮＋无人机的协同锁定。

**软联动**只增添一道可见效果（闪电、标记、反击），强度要有上限；**真正EVO**才替换弹道/攻击方式；**双满级融合**再释放装备槽。三级的差别比单纯“+20%伤害”更有动机。

## 6. 三选一界面怎么画（390×844竖屏）


top HUD：船体/航时/零件；下面两排短图标：


default主动 [主炮★☆☆] [无人机★☆☆] [电弧☆☆☆] [空]

被动 [超导电容★☆] [空] [空]

当前升级三选一（暂停游戏，三个大按钮）：

- **追踪无人机 Lv1→Lv2** / 追踪更快，显示“与电弧可形成雷暴蜂群”；
- **超导电容 Lv1→Lv2** / 更稳定放电，显示“电弧进化前置”；
- **震荡导弹 Lv1** / 新开一个范围攻击流派。

如果主动已达3星且对应被动满足：优先提供金色“进化·星链雷网”卡，并注明“替换原电弧，不额外占格”。如果同时拥有两件3星主动，出现紫色“融合·雷暴蜂群”卡，提示“合并两槽，空出1格”。

**每张卡必须同时展示**：类型（主动/被动/进化/融合）、当前→升级等级、效果变化、距离目标EVO还差什么；不在画面上堆一整张复杂合成表，详细配方放二级“武器图鉴”，只显示已经获得或已见的内容，隐藏未知终极武器名称。

## 7. 对局节奏与上限

| 时间目标（QA候选） | 体验 |
|---|---|
| 0～15秒 | 自动主炮第1次击中，玩家只拖动躲避 |
| 15～30秒 | 首次三选一，可以得到第2件主动或1件被动 |
| 35～60秒 | 至少一次**软联动**可见，但不强制随机刷出唯一路线 |
| 75～120秒 | 精英出现与EVO宝箱提示；正常路线有机会达成**至少一种**EVO |
| 120秒左右 | 折返信标让玩家继续深入或安全结算 |
| 继续深入阶段 | 可以追求2件Lv3的融合，例如雷暴蜂群 |

所有单局设备升级、EVO和双武器融合都**在结算后重置**；局后永久升级/收藏另外保存，不复用旧v0.5.1的玩家资金。

安全限制：单屏避免超过60个弹丸与40个敌人，电弧单次最多3～4跳且有独立冷却，30FPS为低端机候选底线。具体要测真机，不能把一份设计稿当性能通过。

## 8. 分阶段实施，不一次性做20件

**下一迭代 Demo 0.2，只做：**

1. 用现有4主动（主炮/无人机/电弧/护盾），新增3被动（聚能透镜/超导电容/反应装甲）；
2. 实现3条主动+被动EVO（贯星轨炮、星链雷网、反应壁垒），以及1条双满级融合（无人机+电弧→雷暴蜂群）；
3. 让三选一卡片可见“搭配提示”，在精英宝箱里完成一次真实进化或融合；
4. 提供武器槽布局、用相同敌群比较DPS/伤害与可见性，真实360/390竖屏检查；
5. 这个阶段**不接回旧的四船、货舱、黑市和钱**，独立存档，确保没有复杂化。

**验证之后才扩展：**第2批补导弹/旋刃和3个其他被动、剩余3条EVO和另一条融合；只有体验足够强，才决定是否让它成为正式v0.6主循环。不得为了增加内容而把所有图标放进第一页。

## 9. 玩家需要决定的三个体验问题

- 进化后，是否**第一眼看出机制变了**（而不仅仅是数字/名字）？
- 发生无人机+电弧融合时，是否觉得自己这局做出了有价值的Build决策？
- 第一趟折返后，是否更想再次起飞，追求还没合出来的第二种武器？

以上均为设计候选。用户审核后 Codex 才开始 Demo 0.2；不修改已交付的 Demo 0.1 和正式 v0.5.1。

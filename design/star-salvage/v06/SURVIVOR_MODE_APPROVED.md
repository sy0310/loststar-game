# v0.6 新主玩法定案｜《失物号：星海生存》

> 决议日期：2026-11-11。用户明确选择**吸血鬼幸存者式星际像素肉鸽**作为下一代游戏的核心，不再继续做旧“探索航点→装舱→返港→黑市”循环。不是要把现有飞船和已购档案删除，而是停止把旧探索机制当主游玩。研究参考 Survivor.io 的单手移动、主动/被动技能、肉鸽升级和局内进化，但画面、美术、数值、角色、关卡均原创。
>
> 用户认可的视觉方向是较丰富的紫灰、暖金、冰蓝像素科幻战斗，明显的弹幕、拾取、护盾、连锁闪电、升级和融合表现。**不用旧简陋线框当最终美术。**
>
> 本文件确立*玩法方向*；具体角色/图形/触控尚须真实用户试玩和移动端验证。现有v0.5.1/TapTap469033/旧schema8及所有已购权益留存回退。

## 1. 一局的完整循环

**开始一局 → 360°自由移动躲避敌群 → 自动朝近敌攻击 → 掉经验/零件 → 三选一升级 → 满级进化/融合 → 精英与Boss → 3分钟结算 → 轻量永久强化 → 再打一把。**

- 手机仅一指虚拟摇杆（浮动摇杆），电脑键盘/WASD作为QA操作。
- 开始无需选节点/读文字/买燃料。第一批敌人在数秒后出现。
- 围攻来自四面，镜头跟随飞船，星域是滚动二维空间，不是原“只能向上射击”的飞机大战。
- 一局目标约**3分钟**，70秒精英、130秒Boss；死亡可迅速重开。此时间是原型候选，试玩可调。
- 奇遇/彩蛋变成可见的星空异常、独特敌人和战斗掉落；不再用长文本卡中断动作。
- 不做原返航油耗/虫洞8油费、点选航点、手动拼货舱、常规黑市和重复任务。这些旧代码、原版私有存档留审计和回退，但不进入新主循环。
- 不引入PvP、卡牌装备合成、实时联机、挂机领钱、强制广告、多个经济货币、十分钟长局或大世界剧情。

## 2. 武器/被动/进化（原型已经有实际行为）

**主动4格**（初始脉冲主炮占1格，主动最高Lv3）；**被动3格**（Lv2满级）。升级三选一，特殊合成出现专属卡。

| 主动 | 职能 | 指定被动 | 满级进化 |
|---|---|---|---|
| 脉冲主炮 | 近目标自动射击 | 聚能透镜 | 贯星轨炮：穿透光束 |
| 追踪无人机 | 轨道副炮锁定 | 锁定芯片 | 猎手蜂群：多机协同 |
| 电弧线圈 | 连锁闪电 | 超导电容 | 星链雷网：更长链路 |
| 震荡导弹 | 追踪爆炸AOE | 冷却矩阵 | 彗星弹幕：多枚轰击 |
| 旋刃护卫 | 近身环绕收割 | 回收磁场 | 磁旋收割阵：大范围近防 |
| 离子护盾 | 减伤与反击 | 反应装甲 | 反应壁垒：护盾冲击 |

双主动**均Lv3**才能选择真正的融合，原两主动合并一件并释放1主动槽：

- 追踪无人机＋电弧线圈 → **雷暴蜂群**：无人机追踪命中后连锁电击。
- 震荡导弹＋旋刃护卫 → **爆裂刃环**：环绕攻击产生范围爆炸。

单武器进化后不再参加双武器融合；普通低级联动可以在满级前体验，作为短期反馈。融合与进化效果应当改变**实际伤害/弹体/范围与可视特效**，不只是套个文字名。

## 4. 视觉实现标准（不要原样照搬其他游戏）

基准：用户刚认可的《失物号：星海突进》三手机战斗/升级/进化概念板，风格方向是高对比深紫星域、蓝电、金黄经验爆闪、像素机械Boss、清晰三选一、进化庆祝。

首轮真正运行美术至少要做到：
1. 单一像素比例的飞船/4类小敌/2精英Boss源图（透明、完整、轮廓可辨、镜头缩放无糊图），优先可编辑像素素材；不要把概念图整块裁切充素材。
2. 命中闪白、伤害跳字、被击反应、敌人死亡爆粒、经验晶体吸附、UI经验条增长可见；低端机粒子数有上限。
3. 六主动至少在射弹样式/形状上可辨，进化时更强的弹幕/电网/旋刃/护盾必须真正不同。
4. 升级弹出暂停游戏，三张卡在390×844及360×800首屏可读，卡片用原创像素图标，避免复杂层叠和每个页面长滚动。
5. 船体/升级UI不要遮战场。Boss一条血量条，屏幕更多是战斗不是按钮。
6. 视口、刘海、锁屏、方向变化、WebKit/Chromium真实HTTP测试；实际手机帧率与发热由设备复测，不用桌面截图代替。

## 6. 评估优先级

程序正确性过关是底线，但玩家想主动再来一把才是核心。收集以下实际反馈：首10秒是否明白怎么操作，首30秒是否有升级，主动+被动能否看懂，满级融合是否爽，3分钟后是否主动再玩；重点观察**第二局自发开始比例**，而非加了多少按钮或材料。

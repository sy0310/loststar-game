# v0.6.6 精英战利品与船体修复

本轮沿用已认可的15分钟生存、6＋6槽、八条5＋5进化与四条双进化融合，集中处理本次试玩反馈。

## 本轮要求

- RECOVERY 保留低于35%船体时升级必有的可选28点修补。精英实体修理包提高到24点，Boss修理包32点，增加清晰十字、绿色轮廓及实际恢复量提示。满场掉落也保留修理收益，原XP和零件分开处理。
- ORBIT 护航无人机椭圆由130×114缩为116×102。晶体内环和副机尺寸沿用认可方案，真实发射与显示使用同一轨道。
- ELITE 精英本体血量提高为原3倍，封锁母舰护甲继续按原30%比例。普通敌机和Boss数值沿用原版。同合法装备实测旧／新定点击杀时间，另记录普通游玩和策略模拟。
- LOTTERY 每次精英战利品总共随机抽1～3级，逐级随机分配到已装备且未满级的主武器或辅助，再合并显示实际结果。单件最多5级，剩余可升级空间不足时如实显示实际级数。结果随存档保存，刷新无法重抽，领取只能一次。装甲增加的船体上限与恢复量实际生效。
- ADVANCE 主武器和专属辅助都满5级才具备进化资格，仍以75%高级卡抽取规则决定是否出现。两件合法进化才能融合。高级卡出现时可选择进化或本次已抽出的普通强化。所有已装备装置满级时，提供现有补给选择。
- COMPAT 规则5只用于新局。已有180／600／900秒在途局保留原规则和战利品方式。原钱包、永久船体／火力、旧星球／首章／航路命名空间及备份安全保留。开发包供用户复审，真机与趣味验收单独登记。

BALANCE_V066.json保存可编辑数值，sync_runtime.py生成实际运行模型。所有既有美术及音乐继续使用。本轮修理包轮廓与十字由Canvas按物品真实位置绘制。

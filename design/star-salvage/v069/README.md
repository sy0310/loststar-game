- SALVAGE069-PICKUP 新局零整备经验吸取半径36，接触领取19。局外天线每级加8、最高增加48，局内磁场保留其已有五级曲线，两条途径独立生效。零件基础150、旧规则2～6经验150、旧规则7经验190保留。开局范围提示使用实际范围，牵引与领取防重复保存继续有效。

## 决定

每局刷新采用3次。刷新只更换普通升级卡，精英已抽的等级和高级机会继续按原记录展示。除经验基础范围外，本轮成长曲线和费用保持v0.6.8配置。

基础经验范围收回到36，以飞船靠近晶体获得初期经验。满天线84，磁场一级71.75，两者叠加119.75。已有天线和磁场继续提供实际范围。新规则用于新局，原对局继续原规则。

当前主动数量已大于槽位，本轮通过修正抽卡与显示真实池解决搭配趋同。武器与辅助的五级／双满级进化／双进化融合仍按原规则运行。

# v0.6.2 深空背景

`deep_space` 为独立静态银河背板。内置 ImageGen 生成原始画面，保留原图及完整提示词。导出仅进行最近邻缩放和48色量化，原生384×640像素，运行使用2×，4×供美术检查。

背景含低亮度紫灰星云、斜向银河尘带、稀疏暖星与远处小型断环遗迹。中央留深蓝空域，敌人和武器继续独立绘制。建议以覆盖画面且留小幅冗余的方式绘制，并限制相机视差幅度。图像边缘未制作无缝循环，不应平铺。

OpenRaster源文件包含完整银河绘画层及一致的合并预览。它是静态背板的可编辑栅格源，星云与遗迹未拆分为独立深度层。运行时近景星点可由现有渲染器另行绘制。

```bash
python3 design/star-salvage/v062/production/space/export.py
python3 design/star-salvage/v062/production/space/verify.py
```

内部素材检查待父级结合360×800和390×844实际战斗复审。明亮攻击线与银河尘带的叠加可读性、真机视觉和性能仍需实际验证。

# v0.6.2 敌机与奇遇来访者

使用内置 imagegen 分别生成五张透明原图。每次提示和原始路径保存在 `prompts.json`，原始 PNG 完整保存在 `originals/`。正式素材经同一逻辑像素网格、既有 v0.6 角色色板转换，原图保留原字节。

| 角色 | 原生尺寸 | 识别点 |
| --- | --- | --- |
| lancer | 28×28 | 青蓝长尖、后掠双翼、双喷口 |
| sentinel | 32×32 | 开口双叉、双琥珀投射器、宽翼 |
| minelayer | 32×32 | 宽货箱机身、成对舱口、青蓝舱缝 |
| courier | 32×32 | 三只实体包裹、金色货架、侧发动机 |
| watcher | 40×40 | 三枚折叠叶片、中央观察眼、金属轴环 |

原生 PNG 为 1×，运行图和高倍导出分别为 2×、4×最近邻整数放大。`native/*.ora` 按装甲、金属与能量拆为三个可编辑层，其合成与原生 PNG 完全一致。这些图层由正式原生图整理生成，原始生成稿仅提供像素创作来源。

光源统一为左上方，轮廓使用既有紫灰暗部，危险与技能器官保留高对比识别点。`native-edits.json` 记录降采样后恢复可读性的少量像素。主审核提出的布雷机修订只调整两组舱灯和一条中缝，保持原机身比例和材质。

图片只含机身。喷口、碰撞中心与原生半径在清单中登记，推进尾焰、警示线、束流、布雷及奇遇出场由运行逻辑独立驱动。所有角色为原创科幻设计，未使用现成电影角色或第三方游戏贴图。

```bash
python3 design/star-salvage/v062/production/actors/export.py
python3 design/star-salvage/v062/production/actors/verify.py
```

`native-contact.png` 同时提供 4×细节及实际 2×大小。五图通过静态尺寸、透明度、色板、文件摘要、原生边距、整数放大与可编辑层合成验证。实际战斗接入、用户视觉和真实手机体验分别待验证。

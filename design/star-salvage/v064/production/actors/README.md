# v0.6.4 精英新机体

两张独立透明顶视原图使用内置 imagegen 制作。提示、原始输出路径、所用工具与母舰定向返修记录保存在 `prompts.json`，原始 PNG 完整保存在 `originals/`。

| 角色 | 原生画布 | 运行显示 | 主要识别点 |
| --- | --- | --- | --- |
| elite_raider · 追猎先锋 | 40×40 | 80×80 | 三尖 W 形前叉、琥珀中轴冲锋枪头、双后喷口 |
| elite_warden · 封锁母舰 | 48×48 | 96×96 | 宽盾肩、左右各三矿舱、实体紫色重力核心、双后喷口 |

母舰首稿偏纵长，使用内置图像编辑重新构造短中轴与横向盾肩。选定原图等比缩格，机身包围框为 46×26 原生像素。首稿也保留供审核追溯。

装甲使用既有 v0.6/v0.6.2 角色的 28 色紫灰、暖金、青蓝调色板。实体核心额外使用既有武器和效果中的四个紫色。高饱和紫色只用于核心能量区，金属仍使用原角色色板。所有生产 PNG 为二值透明，无画入机身的尾焰、攻击特效、外光环或 UI。

`native-edits.json` 记录缩格后恢复琥珀枪头、青蓝喷口内灯和紫核识别度的少量像素。它们只改变现有机身内的颜色，轮廓和物件结构保持一致。

主代理初审保留两种机体轮廓，仅要求提升母舰紫核与六个矿舱开口的原生可读性。最后修订为四个核心内高亮像素，以及每个矿舱各两像素的独立暗色开口与青蓝内灯，未加外光环或整排栅格。

`native/*.ora` 包含装甲、金属和能量三个可编辑材料层，合成与 1× PNG 逐像素相同。ORA 由正式原生图整理生成，完整生成原图提供创作来源。2×/4× 素材通过最近邻整数缩放导出，运行目录为 `prototypes/salvage-survivor-demo/assets/v064/actors/`。

清单中的中心、碰撞中心及半径采用原生像素单位。圆形碰撞范围取中部实体的保守近似。两个真实喷口的内灯中心登记在 `nozzleCenters`，外接尾焰起点位于喷口后缘，登记在 `exhaustAnchors`。顶视朝向为 `[0,-1]`，尾焰排出方向为 `[0,1]`。

```bash
python3 design/star-salvage/v064/production/actors/export.py
python3 design/star-salvage/v064/production/actors/verify.py
```

`contact-sheet.png` 同时展示 5×细节与实际 2×大小。验证覆盖两张原生图、两份 ORA、四张整数导出、色板、二值透明、边距、文件摘要、喷口登记和母舰宽短比例。主代理负责实际接入和视觉复核，用户视觉与真实手机表现均待审。

依据用户474099实机反馈执行，继续同一Draft PR。当前源码和原玩家档案保留，普通入口新局采用900秒规则。旧180秒、旧600秒和两种旧成长规则继续续玩。

## 本轮执行要求

1. 恢复普通敌机2倍原生像素的已认可体量，机体、喷口、尾焰、血条与碰撞范围共同复核，截图与真实绘制几何分别验证。
2. 折跃棱镜使用环绕晶体与实体晶片，折射晶核提供实际折射，进化形成更完整星阵。贯星轨炮保留长直贯穿的身份，两者具有清楚的攻击差异。
3. 雷电随阶段使用蓝、金、紫配色，雷暴蜂群融合具有明确的紫金放电。颜色和实际等级／进化状态对应，旧在途规则保留。
4. 普通蜂机弹锁定发射时的敌方位置后直线前进，普通导弹直射选定区域并爆破。追踪只由合法5＋5后取得的进化／融合提供，已经飞出的普通弹不会因后来进化自动追踪。
5. 新局900秒，放缓前期经验节奏，后段继续增加有可避预警的交叉火力与精英压力。保留5＋5、随机75%战利品和四条双进化融合，原永久强化费用与权益继续使用。
6. 三种实体精英拥有不同轮廓与能力，追猎者冲锋与扇射，破阵先锋突进与交叉针弹，封锁母舰护甲、布雷与扫射。Boss继续同场景升级攻击压力，全部攻击具有实际伤害和可见结果。
7. 存档保存900秒规则、晶片发射属性、精英特性和进度。旧180／600秒、27049零件、旧融合、原星球／剧情／航路档案、并发与一次结算继续回归。
8. 实际HTTP双引擎两尺寸、旧档、模型策略、自然十五分钟、明确标记的攻击／进化QA录像、固定包与Mac原入口验证后上传TapTap开发自测。用户视觉、手指操作、手机声音／锁屏／发热与趣味分别待审。

## 制作与复核

先核对上版缩放回归并恢复体量，制作两种新精英的原始图与分层像素素材。主代理审核轮廓、比例、原生像素与实际手机尺寸的同屏画面。既有飞船、银河、音乐和认可轨炮继续使用。

五级成长和十五分钟压力采用独立战斗版本3，保留版本2完整曲线。新的经验、敌机压力和轨炮频率会用真实策略与普通入口重新检验，实际原值、新值和原因记录于本轮平衡报告。

# v0.6.10 · 渐进修补与测试资料

本轮只调整消耗一次升级机会的即时修补，准备首轮测试资料。已认可的武器、槽位、随机选卡、三次刷新、费用和收益继续使用v0.6.9数值。名称沿用既有宣传稿《失物号：星海突进》，后台当前名称为“失物星球”，资料名称待用户确认。

## 本轮要求

- SALVAGE0610-REPAIR 消耗一次升级机会的修补，按本局战斗时间与船体上限增长，卡片显示实际恢复值，暂停时间不增加恢复量，重复输入只生效一次。
- SALVAGE0610-COMPAT 旧对局保持原恢复规则，新局启用repairScalingVersion1；余额、设备、工程、预约、原有存档与历史备份保留，双引擎两竖屏与真实旧包迁移单独验证。
- SALVAGE0610-NAME 测试名称使用《失物号：星海突进》，与已存在宣传标题一致，记录后台旧名与待用户审核状态。
- SALVAGE0610-ICON 提供独立方形游戏Logo，保留原图与提示，检查1024、512及实际小尺寸辨识度。
- SALVAGE0610-PROMO 提供1920×1080横图和1440×1440方图，统一紫灰、紫金和青色飞船身份，逐张审图与平台规格检查。
- SALVAGE0610-SCREENS 提供当前冻结包的真实运行截图与连续录像，标明普通开局和QA预设装备来源，记录源码SHA，真机验收单列。
- SALVAGE0610-INTRO 提供可直接使用的简短介绍、卖点和基础操作，描述已实现玩法，组成完整可审核资料包。

## 恢复规则

一次修补的容量为 `round(船体上限 × (0.28＋0.42×战斗时间／900))`，实际恢复受缺失船体上限限制。战斗时间限定0～900秒，选卡、暂停、后台均不推进。正常低船体出现条件沿用原模型，消耗当前一次升级选择，零件费用为0。

| 战斗时间 | 基础100船体 | 永久船体升级后148船体 |
| --- | --- | --- |
| 0分钟 | 28 | 41 |
| 5分钟 | 42 | 62 |
| 10分钟 | 56 | 83 |
| 14分钟 | 67 | 99 |
| 15分钟 | 70 | 104 |

新局增加独立功能标记，战斗规则版本仍为8。已保存的旧局缺少该标记时恢复28，继续完成后新开一局启用递增规则。原存档无需重置。

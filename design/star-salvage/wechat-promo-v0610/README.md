## 设计与来源

封面用“一指走位 / 火力进化”和十五分钟玩法短句，放大同一艘紫灰白金飞船与青色座舱。横图、竖图继续使用“失物号 / 星海突进”标题和紫金星环。三张玩法图采用共同金紫字效、简短说明及原始游戏画面排版。[六图总览](review.jpg)

四份新插画由内建image_gen生成，参考仓库现有原创宣传图。原始输出保存在originals，逐项提示与参考路径保存在prompts.json。横竖主视觉属于宣传插画。实际游戏图采用等比缩放、完整保留源画面的排版。

- 一指走位使用v0.6.10普通开局PNG。
- 武装成长与融合火力分别取自现有连续实操录屏19.15秒和12秒。该录像从合法中后期配装检查点开始，使用真实移动、攻击、伤害和强化，图内标注“进阶配装演示”。
- 游戏画面来自桌面Chromium的H5运行包。微信版采用同一战斗控制器与美术，微信HUD与菜单布局可见于微信适配交付记录。

来源文件大小、摘要及实际视频的准备范围已登记。[清单](manifest.json) · [原实操录像证据](../../../artifacts/survivor-v0610-active-video/evidence.json)

## 检查结果

六张最终JPG均逐张实看，游戏标题、玩法短句和说明文字可读。封面650×250、69,673字节，符合用户截图规格。其他五张尺寸固定且每张小于1MiB，具体上传限制以对应字段为准。

主视觉的飞船轮廓、青色座舱、双轨炮及紫金光效与既有宣传图对应。三张介绍图中的HUD、数值、强化内容与源画面一致。当前素材等待用户挑选和平台处理。

微信公众平台的页面交互受此前站点安全策略拦截，后台上传与保存待用户操作。每月封面修改次数由平台记录，当前提供的截图显示0/3次。

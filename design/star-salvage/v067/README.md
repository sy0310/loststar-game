# v0.6.7 三层武装、维修舱与局外成长

本轮执行用户确认的四项反馈，继续十五分钟自动攻击生存和6＋6槽位。

## 本轮要求

- LOOT 精英随机强化总共1～3级，每一次＋1都有自己的图标。不同物品分别显示，同一物品连续升级也显示对应次数。实际等级结果、刷新保留和一次领取同时验证。
- REPAIR 新局采用两种主要修复取舍。低于35%船体时升级可选恢复28点，或获取／升级占1武器槽的自动维修舱。维修舱五级每秒修复0.25、0.4、0.55、0.7、0.9点，随有效战斗时间推进，暂停与后台停止，满船体封顶。新局精英与Boss沿用战利品升级，现场修理包交由旧规则保存局继续使用。
- ORBIT 无人机内圈56、棱镜中圈108、旋刃外圈152／进化156。基础、进化及融合共同遵循层次顺序。真实发射源、刀刃触碰与实际图像共享几何，保持认可的机体尺寸和各武装特性。
- GROWTH 增加推进器、回收天线、装甲衬层三条6级工程，每级分别提供2%移速、8拾取距离、2%减伤，并有尾焰、天线及装甲灯片反馈。每条费用300／500／800／1200／1700／2300，共6800零件，三条20400。原船体和主炮工程保留原价与已购权益。200零件预约下一局六种起始武器之一，正常出发占1武器槽，出发前可取消并全额退还，默认主炮免费。工程、预约在本局结算后操作。模型覆盖新手、27049旧钱包及0／5／15／30／60／120分钟收支，实际账本、取消、并发与写入失败单独验证。
- COMPAT 新局规则6，旧180／600／900秒规则2～5局保留其已存规则。工程使用可选增量字段，首次购买才写入。余额、旧收藏／航路／首章、船体与主炮等级、EVO、融合、存档及备份保留。真实旧包迁移、双引擎双尺寸、刷新续玩、原生Safari、固定ZIP和TapTap自测分别提供证据，用户视觉、趣味与手机验收单列。

BALANCE_V067.json为可编辑数值源，production/repair含两项实际image_gen原始图、提示词、原生PNG、分层ORA与确定导出。运行素材在原68项PNG上增加维修舱机体与图标。

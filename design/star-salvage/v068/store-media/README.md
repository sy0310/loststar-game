# 首版商店素材候选

《失物号：星海突进》的图标与宣传插画候选。父代理已内部接受图标、加字横版和重新构图的方形宣传画的主体、配色、炮座、构图与准确中文标题。当前状态为首版素材候选，等待用户审核。

## 来源与生成记录

本轮四次均使用内建 `image_gen.imagegen`。图标参考仓库内真实玩家原画、实际玩家精灵与已实现的双轨炮挂载。横版参考同一玩家和挂载、已实现的裂隙织网者原画与奇点环图标。标题版以无字横版为编辑目标。方形宣传画使用加字横版和真实角色原画重新构图，标题在左上、裂隙织网者在右上、装备双轨炮的主角占据下方主体。完整提示分别保存在 `icon-prompt.txt`、`hero-prompt.txt`、`hero-title-edit-prompt.txt` 和 `square-promo-prompt.txt`。

`originals/` 保留四张内建工具生成的原始字节。`candidates/` 为对应原件的相同字节副本，方便审核。工具返回的图标与方形宣传画原图为1254×1254，横版原图为1672×941。原始路径、来源、尺寸、文件大小、SHA256与运行时目录映射见 `manifest.json`。

这些生成图承载商店宣传用途。游戏中的正式原生PNG和分层工程继续以各版本资产登记为准。本目录内的生成图以完整位图交付。

## 可重复技术导出

运行 `python3 design/star-salvage/v068/store-media/export.py`。

导出沿用仓库的Pillow技术链，以 `Image.Resampling.NEAREST` 对完整画布进行尺寸转换并保存RGB PNG。方形画布完整保留，方形宣传原图技术放大至1440×1440。横版1672×941转换为精确1280×720预览与1920×1080横幅，宽高比例差约0.05%，完整画面均保留。此步骤只处理输出尺寸。主体、文本和构图均来自对应内建工具输出。输出尺寸、摘要和来源见 `export-report.json`。

## 实际规格与一命令核验

父代理本轮回读TapTap素材上传规格。横幅最低1920×1080，方形宣传图最低1440×1440，均接受PNG/JPG且单文件至多4MB。`manifest.json`登记 `header_banner` 横幅用途、对应 `banner_4` 上传要求以及 `square_promo_image`。当前所有导出PNG均小于4,000,000字节。

在仓库根目录运行 `python3 design/star-salvage/v068/store-media/verify.py`。

核验覆盖参考与提示摘要、生成原件和候选副本字节一致、PNG尺寸与RGB模式、单文件大小、TapTap最低尺寸与长宽比，并在内存中重做每张技术导出后逐字节对照。结果写入 `verification.json`。该命令可重复运行。

本目录交付范围为本地素材准备和审图候选。

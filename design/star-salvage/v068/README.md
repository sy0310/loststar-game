# v0.6.8 首版试玩返修

本轮沿用紫灰像素科幻、十五分钟单局、六主动和六辅助。基础武器及辅助最高5级，双满级后从合法精英战利品抽取进化，再以两项进化武器融合。首版开发自测继续由用户审阅。

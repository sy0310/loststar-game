# v0.6.1 十分钟战局与音画升级

用户于2026年11月11日在TapTap469298试玩后确认核心玩法正常，要求延长至10或15分钟、扩展武器与增强格、加强组合特效，并增加武器音效、背景声音与音乐设计。

本轮采用10分钟、6主动／6增强。为保留六格下的组合取舍，增加折跃棱镜与引力锚、两对应增强、两进化及一融合。仍为同一生存竞技场和现有升级机制。

## 执行规则

1. 新局600秒，原v0.6.0在途快照仍按180秒及4／3槽位结束。原零件、强化等级、已结算记录保留，同一存档命名空间安全续接。
2. 6主动／6增强，新内容补到8主动、8增强、8进化、3融合。当前已认可的六原武器、图标、飞船及敌人保留。
3. 首20秒左右升级，130秒第一Boss，后半程安排第二与最终威胁。保持40敌左右的明确上限，以武器形态和敌潮节奏构成十分钟内容。
4. 六类原武器各有可辨的发射、命中、轨迹或护盾反馈，新增折射分束和引力吸聚具有实际作用。进化／融合有短促聚焦、展开、收束演出，尊重减少动态设置。
5. 多种搭配的全场效果仍需看清玩家、危险弹与经验。粒子／声音并发、爆炸和电链设置上限，实际双引擎测量。
6. 武器音效、受击、拾取、升级、进化、Boss各有声音。首个用户手势解锁，暂停／后台停止，恢复不叠播。音乐和音效可独立调节，偏好独立保存。
7. 用户已提供并认可Nebula Groove与Nebula Loop两首MP3。保留原件，运行时流式交替，2秒淡化衔接；程序合成仅作为失败回退。
8. 新手与满强化策略覆盖600秒，记录首次升级、进化／融合、关键分钟、死亡、Boss与结算。自然录像和QA靶场分别标注。
9. 原TapTap469298与冻结04ad5a8、旧v0.5.1/469033及全部旧档留存。新版本通过工程检查后上传TapTap开发自测，继续Draft。
10. 卖点从真实操作录像提炼，重点展示单指驾驶、多武装交叉火力、可见进化与真融合，以及十分钟中段／末段的变化，不以测试通过代替用户趣味审核。

# v0.6.5 武装体量与敌舰辨识

依据用户对474770的手机反馈实施，继续同一Draft PR。当前产品为十五分钟360°星海生存，自动攻击、五级武器与五级辅助、随机战利品和双进化融合。

## 本轮要求

1. 普通无人机放大并使用外侧巡航椭圆，棱镜使用内侧晶阵。发射点与可见机体使用同一位置计算，在360×800与390×844同屏区分。
2. 八件进化武装及四融合有清楚可见的主体、弹体或特效成长。保留像素尺度、原伤害来源与实体上限，敌方预警和玩家机体仍可辨。
3. 星舰壁垒拥有独立双炮护卫挂载、专属图标、充能与贯穿光束、护盾反制表现，实际攻击和已购权益沿用已有模型。
4. 五类精英具有实际可分辨的轮廓与主要攻击。保留三类已有精英，新增折返截击者与跃迁蜂巢，弯曲截击与有限实体小机群分别验证。
5. 四场Boss使用四种可辨身份，新增三型正式像素源图，各自具有至少两种主要攻击及半血阶段变化。螺旋、重型弹、钳形能量墙具有对应预警、轨迹和实际伤害。
6. 新战斗规则版本4保存新敌舰身份、攻击阶段和发射记录。旧180／600／900秒规则、27049零件、原永久强化与全部其他游戏命名空间保留，原价格、五级门槛、75%和十五分钟继续使用。
7. 输出固定包的实际HTTP双引擎／两竖屏、真实旧ZIP迁移、刷新与关闭重开、策略与经济、普通连续十五分钟以及明确标记QA的武器／敌舰录像，更新原Mac试玩与TapTap开发自测。
8. 原346项要求和历史证明保留，本轮逐项追加。用户视觉、手机触控／跨包续档／锁屏／听感／发热与趣味单独待审，继续Draft。

## 位置与动作

新局棱镜为内侧约40～51逻辑像素晶阵，无人机为外侧约130×114逻辑像素巡航椭圆。普通副机先达到可读体量，进化与融合再通过独立机体和较大弹体强化。碰撞、范围和发射使用真实同源位置，进化追踪仍需实际取得对应进化。

四Boss沿用300／440／650／850秒，依次为现有星海守卫者、裂隙织网者、机雷方舟、双相裁决舰。新精英分布于原精英时点，保留原战利品队列与一击退一奖励。新身份可在普通游玩遇到，QA演示另行标记。

新增像素源图由美术子智能体制作，主代理按剪影、像素颗粒、材质、实际尺寸和连续画面审核。原图、原生PNG、可编辑ORA、2×／4×与提示词保留于production。现有银河、主飞船、音乐、原生像素库继续使用。

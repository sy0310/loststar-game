# v0.6.5 副机与最终融合挂载

由内置 ImageGen 分别制作猎手副机、蜂群副机和星舰壁垒挂载的完整透明原图。原图与完整提示保存在 originals 与 prompts.json，生产输出采用现有武器色板、原生像素网格及整数最近邻导出。

## 资源

| id | 原生尺寸 | 内容 | 方向 |
| --- | --- | --- | --- |
| hunter_drone | 28×28 | 宽翼双炮、金色反应核、双尾喷 | 上 |
| hive_drone | 32×28 | 宽短双电叉、并列紫电容、双尾喷 | 上 |
| bastion_mount | 40×40 | 双轨炮、护盾炮座、后U桥、中央透明腔 | 上 |
| ionbastion | 24×24 | 独立双炮与六角盾图标 | 上 |

蜂群首个生图候选偏长，原件保留为 hive_drone-initial.png。第二次定向生图将电容并列、翼肩加宽、前叉缩短，最终采用该宽短轮廓。父线程实际2×审图后，原生修订提亮真实炮口、核心和尾喷，并加厚挂载炮座与双轨，修改逐像素记录于 native-edits.json。

挂载保留原生矩形 `[11,6,29,28]` 的18×22透明腔，中心锚点 `[20,20]`。左右炮口分别为 `[7.5,2.5]`、`[32.5,2.5]`。中心腔用于展示现有玩家机体，两侧炮座承担视觉连接。它的两个蓝色炮座口用于能源表现。副机喷口与尾焰锚点单独记录，融合图标由既有24px图标语言独立绘制。

ORA由生产原生PNG按装甲、黄铜、能量重新分层，和生成源图分别留存。每个2×/4×导出都和1×像素逐项比较，真实alpha仅含0/255。contact-sheet.png包含4×细节与实际2×尺寸，供主线程对照游戏画面审核。

## 重复导出

```bash
python3 design/star-salvage/v065/production/weapons/export.py
python3 design/star-salvage/v065/production/weapons/verify.py
```

本目录只完成独立美术生产与静态校验。主线程运行接入、连续画面、手机观感及用户最终美术审核分别登记。

# v0.6.5 三种原创 Boss 机体

三张原图分别使用内置 imagegen 独立生成。真实原始 PNG 保存在 `originals/`，完整提示和原始输出路径保存在 `prompts.json`。这些原图是生成源参考，正式原生与材质图层在后续生产中整理。

| 标识 | 机体 | 轮廓与实际器官 |
| --- | --- | --- |
| boss_weaver | 裂隙织网者 | 上方开口弯月双臂、中央独立折光核、两端束流发射器、下桥双后喷口 |
| boss_ark | 机雷方舟 | 横宽厚重货舰、六个独立弹舱、中央甲板、前方开口船坞、双后喷口 |
| boss_judicator | 双相裁决舰 | H形两长舰体、桥接核心、双前端轨炮、双后喷口、前后中间负形 |

三者原生画布均为 64×64，中心 `[32,32]`，顶视朝向 `[0,-1]`。机身最大边约56像素，保持原图宽高比例。2×运行图为128×128，4×为256×256，透明边距保留在画布内。

统一使用 v0.6.4 角色色板，紫灰装甲、暖金机械接缝、青蓝发射器及推进器内灯。织网者装甲的白色高光限制为银灰，最亮区域留给中央悬核，避免缩格后出现断碎白边。少量后续原生修订记录在 `native-edits.json`，不通过程序几何替代机体美术。

`native/*.ora` 按装甲、金属与能量分为三个可编辑材料层，合成与1× PNG相同。2×/4×仅做最近邻整数放大。生成源参考没有被描述为已带分层的原画或动画。

## 几何与碰撞建议

所有喷口、发射器、圆心、半径采用原生像素坐标，运行放大2倍。`nozzleCenters` 是喷口内部，`exhaustAnchors` 是后缘外接尾焰起点。`shotNozzles` 是前端真实发射口，方舟另登记六舱的 `launcherAnchors`。

织网者双束口为 `[18,8]`、`[46,8]`。方舟前坞重雷口为 `[32,24]`，六个舱口位于横向两组 `[10,32]`、`[17,32]`、`[24,32]` 与 `[40,32]`、`[47,32]`、`[54,32]`。裁决舰双轨炮口为 `[18,5]`、`[46,5]`。

`collisionRadius` 是基于中央实体的保守回退半径。`collisionCircles` 提供按机身、核心、双臂/双舰体及下桥分别布置的建议多圆。织网者的U形内部和裁决舰纵向空隙应保留为空区，实际运行接入应共同旋转各局部圆。圆形是碰撞近似，原生 `contentBBox` 与每圆实体覆盖比例供主审核核对。

三种保守回退半径分别为7、8、5原生像素，仅代表中央核心/甲板。多圆分别为10、7、9个。另记录9个 `openSpaceSamples`，实际原生透明，且不属于任何建议碰撞圆，用于避免把前方开口、U形与H形内部直接当成实心。

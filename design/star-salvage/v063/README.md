# v0.6.3 五级武装与精英战利品

本轮依据470518手机反馈，继续十分钟360°生存。六个武器槽、六个辅助槽，原飞船永久强化价格、余额和数据库继续使用。

## 本轮执行要求

1. 八种主动武器与八种辅助各有1～5级，每级产生实际作用，双方5级后具备单武器进化资格。
2. 进化卡只进入精英／Boss战利品三选一。击退实体后直接升一级，保留已有经验。符合条件时有75%概率出现一张随机进化／融合卡，普通升级继续提供武器、辅助和补给。
3. 两件已进化武器才能进入终极融合。四组为无人机＋电弧、导弹＋旋刃、棱镜＋引力、主炮＋护盾。融合释放一格，继承辅助，使用真实攻击和原音频总线。
4. 普通武器组合保留主炮／蜂机／护盾与电弧的联动，增加导弹命中后的旋刃碎片、引力场形成时的棱镜聚束，并显示短暂现场反馈。
5. 两种已有原创奇遇从实际可见战场跃迁入场，显现护盾持续1.6秒，最后1秒预警。显现结束发出真实攻击，使用实体血条、原机体、真实伤害与一次结算。调整体型和耐久以保留观察时间。
6. 奖励队列、概率结果、三张选卡、随机种子及终极融合进度进入原对局快照。刷新／关闭续玩保持结果，同一精英不会重复发奖。
7. 保留旧180秒与旧600秒在途规则、已有进化和融合。旧局入口提示“原规则”，下次新局启用5＋5。原始4ca726f包在同源隔离HTTP中直接升级验证，原玩家数据库与旧玩法档案保持兼容。
8. 交付固定源码包、真实HTTP双引擎双竖屏、自然十分钟与明确标记的QA录像、实际Mac和TapTap开发自测，继续同一Draft PR。

## 数值与验证方式

每次精英奖励只抽一次75%资格结果，并保存该结果。出现多条合格配方时，随机抽取一张。刷新和查看不会增加奖励机会。

五级曲线沿用既有攻击公式，通过独立等级映射补足中间档。满级输出与旧满级接近。原3＋2在途局保持原曲线。初轮普通升级过慢导致多数模型提前失败，已保留原始失败报告并调整经验曲线，使用最终包重新模拟。

首次升级经验112→72。后续经验曲线从80＋38n＋8n^1.4调整为56＋14n＋2.5n^1.4。首次升级与完整十分钟的真实操作时间，分别记录浏览器自然路径和模型结果。全部既有永久升级仍为70/140/210及90/180/270。

现有精英与守卫采用同场景，增加160、250、340、430、520秒的精英机会，保留70秒精英和130、310、550秒守卫。同类尚在场时，后续机会等待实体被击退，实体不会被回血或重复发奖。

内置QA可显式固定奖励概率与配置，使用隔离数据库。自然入口没有QA控制。工程、内部画面、用户视觉和手机体验分别记录。

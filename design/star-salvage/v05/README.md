1. 12个短奇遇+6个轻彩蛋，重点改变首两站总是重复的抽取模式。
2. 四艘船货舱将来可以因船型不同而改变实际可用格，**但先参照成熟竞品比较A/B/C三种方案**，旧候选mask不直接实现；旧满舱/在途保存必须无损。

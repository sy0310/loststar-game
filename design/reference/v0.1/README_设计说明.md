# 《失物星球》首版视觉设计稿 V0.1

状态：设计审阅阶段，不包含游戏工程，不代表全部可直接用于制作的像素精灵。

## 已确定的核心方向
- 定位：竖屏、轻量化、探索惊喜、怪诞猎奇、2D像素＋2.5D球体观感。
- 远征：完整微缩星球居中；机器人在可见球面活动；飞船沿前后分层轨道绕行。
- 星图：未知星域先不显示任何未发现星球的数量、名字、位置或剪影；经扫描、定位后才揭晓。
- 基地：奇物和生物进入收藏空间；玩家看见返回远征后的变化。
- 六颗星球为内部美术设定，游戏开局绝不能一次性透露。

## 本包页面
00 总览，01 基地，02 远征，03 未知雷达，04 新星球揭晓，05 图鉴，06 收藏互动，07 装备升级，08 离线归航，09 异常事件，10 六星生态，11 退货箱星详情，12 动作规范，13 UI规范，14 审核清单，15 六星球生物造型。

## 对美术素材的约束
- 图中许多元素仍为AI生成的概念构图，文字可能存在小误差，不是最终美术源文件。
- 不强制使用复杂3D：可先用精细分层2.5D图、预设前后景遮挡与少量动作帧实现。
- 星球、建筑、角色应分层重绘，机器人及飞船必须与球面遮挡关系吻合。
- 具体游戏数值、资源成本、稀有率尚未设计冻结。

## 待人工审核
1. 星球是否更接近完整3D球体、是否仍像圆形浮岛？
2. 机器人走动时是否会被建筑挡住？
3. 星图是否彻底避免剧透？
4. 六个星球的生态是否有足够差异？
5. 角色与生物的像素密度是否统一？

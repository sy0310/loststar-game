# 已确认美术方向：新重绘概念稿的轻量实现标准

2026-11-05。用户在本会话认可重新绘制的两张概念图，并明确：**技术实现尽量接近这套感觉，不要求照搬全部细节，但不能丢掉美感与质感。**

## 1. 生效范围与参考优先级

本次认可的对象是本会话新绘制的《失物星球探索流程概念图.png》和《失物星球_奇物修复展陈方案.png》，不是此前在运行截图上叠加几何块、框线的 SVG 草图。

- **新版重绘图：正式视觉方向参考。** 紫蓝星空、暖橙地表、紫粉体积星雾、暖金玻璃展陈；工具、材质和物件之间有可信的接触过程。
- **现有游戏：保留世界结构和业务逻辑。** 原有完整微缩球体、机器人/飞船身份、三导航、真实发现、昼夜与存档权益继续承接；允许按新风格重新绘制局部地貌、雾、工具、玻璃及UI素材，不强行保留所有旧贴图。
- **旧 design/v036/01–04 SVG 与 interactive_review.html：仅留历史布局/流程参考。** 它们的色块迷雾、矢量叠加框架及截图拼装外观被用户否定，不再用作正式画质验收依据。
- 本文确认美术方向，不等于动态表现、实际手机性能、经济平衡或正式存档集成已通过验收。两张重绘图是概念图，不是现成的透明分层、动画图集或可直接上线的UI。原图须在后续素材交接时一并提供；本文提交不宣称原图二进制已上传。
- 概念图中的海报边框、三栏分镜、文字、数值、示意问号及周边摆件，不要求逐像素复制。运行界面仍为单屏竖屏，必须看到完整闭合球体，不能因近景化变成裁切半球。

## 2. 可以简化什么，不能简化什么

| 可以减少 | 必须保留 |
| --- | --- |
| 海报外围雕花、星空窗、花草、猫咪及非玩法摆件 | 清晰的视觉中心、统一的像素尺度、材质与色彩 |
| 雾的层数和循环帧数、装饰性星尘粒子 | 雾团独立设计的轮廓、前后体积、遮住/露出地貌的关系 |
| 局部反光数量、背景细碎纹理 | 玻璃后层/物体/前反光的空间关系和可辨物件 |
| 机器人多余关节、工具复杂物理模拟 | 工具落点、承托、擦过、按压、拿起和放下的接触过程 |
| 展柜枝节、每一级配件数量 | 每级至少两处直接可辨的结构/材料变化 |
| 同屏同时播放的小演出数 | 玩家能看懂“点了哪里、发生什么、得到什么” |

总原则：**优先减少数量和装饰，不降低关键物件的美术质量；优先做少量好看的真实动作，不用大量粒子掩盖接触问题。**

## 3. 推荐技术路线：独立美术资产 + 可控2.5D分层

优先复用现有的球体场景、状态与渲染结构，不为本轮画质目标切换引擎或重构成真正的开放世界3D。用独立绘制/清理导出的透明素材、局部动画帧、遮罩和少量连续变换来实现。下面是实现建议，须以手机样板验证成本与效果。

### A. 星雾：设计成场景的一部分

- 绘制2～3种同风格雾团，每团有可分离的背雾、主体、前缘/亮边；内部用明确像素明暗组织体积，不用随机矩形和多边形充当最终素材。
- 首个样板只做**一处雾区和一个真实可揭晓节点**，通过后再扩到每星2～4处。默认3处仍是内容就绪后的候选，不必一次量产。
- 呼吸和轻卷动可用少量循环帧配合缓慢位移，但各层不能像三张纸片同步平移。雾与建筑的遮挡、暖光受照、球面位置和边缘需一致。
- 探明时先让扫描光穿过局部雾层，再由中心或扫描路径向外散开，逐步露出已有地貌/建筑。不得仅把整块雾的透明度从1调到0；可以用少量散雾帧配合局部揭露遮罩实现。
- 雾位从经过美术审核的地表锚区按存档种子抽取并持久保存；只隐藏真实存在且可执行的内容。已发现老档不重新蒙雾，不重复发奖励。星际未知规则不变。

### B. 点击：首页局部反馈，不盖住世界

顺序保持“触点响应 → 机器人收到扫描信号 → 助力工作平滑消耗 → 真实任务完成 → 实际卸货入账”。扫描圈、光迹、机器人的灯或手势都使用同一美术语言。

不用全屏蓝色遮罩、密集浮字或持续弹窗制造反馈。点击助力仍可选、不强制连点；机器人不能因进度改变瞬移。局部观察窗只在关键接触时出现、可收起，不复制另一套动画状态。

### C. 奇物出土：有承托，不是整张物品向上滑

- 首星以收据为唯一完整制作样板。单独绘制土层前后片、污损纸张、接触工具和小碎土。
- 动作顺序：工具松土 → 纸角释放 → 机器人托住/夹稳 → 少量碎土脱落 → 物品落到整理托盘。
- 采用少量关键姿势和可控局部变形即可，不要求完整纸张物理。关键是有固定接触点、重心与停顿，不能只让纸凭空升起。

### D. 擦拭：刷到哪里，哪里变干净

- 清洁纸面、泥层与工具分别保存；用刷毛的真实接触路径更新污渍遮罩。下一次绘制显示这一段泥已被擦掉，而非整件渐隐或直接切换干净图片。
- 刷毛接触时稍压，换位置先抬刷，纸面只做很轻的受力响应。少量尘粒来自接触处，不在无关位置冒粒子。
- 以“刷过的痕迹、原字露出、纸边仍旧”表现价值。状态完成后可重复看演出，但不重复收费、不自动返脏。
- 首版可以是点按钮后自动完成擦拭，不要求玩家手指反复摩擦，维持放置体验；不能为了表现手感引入繁重小游戏。

### E. 修补：材料变化明显，但不补造事实

- 两处破损分别压贴薄纸、纤维或适当加固材料，保留可辨补痕；避免亮金属夹式胶沿。
- 纸角由松散变稳、卷根由卡住变成可展开，至少两处变化在390/360实际画幅可辨。收据本体轮廓及材质要连贯，不是多贴一个图标。
- 工具、补片和纸面共用锚点，依次经历对准、落下、压合、松开。可用3～4个关键姿态，不强求复杂骨骼。
- 原签收缺失继续保留；清洁和修补只改变物理状态，内容结论仍由真实现场证据决定。

### F. 展示、升级与冷幽默

- 玻璃背层 → 藏品与内部阴影 → 玻璃前缘/少量高光 → 铭牌；空间感通过层次和一致受光实现，不是透明矩形盖在物品上。
- 展柜结构升级继续采用免费基础柜、灯座铭牌、专属微景机械、独立典藏舱。用安装/点灯/机械启动作为反馈，复用准确台架锚点；既购等级不重复收费。
- 物理整理、本体能力、展柜外观分别保存；不因换柜就生成新证据或新能力。
- 笑点由物品行为触发：收据展开后设备打印“您尚未购买任何商品”；胶带先缠牢实际纸路，再小声道歉。打印小票明确是风味回应，不是原始签收证明。避免只增加一段解释文字或单独笑话按钮。
- 样板先保留收据一个笑点。六件组合梗、其他高级能力和多星内容都排在基准通过之后。

## 4. 资源与性能约束

- 禁止整张概念海报直接作为可玩场景。产出可独立编辑的背景、区域、雾、角色、工具、奇物、泥层、修补层、玻璃层与UI；保留源图、透明边界、锚点、遮挡次序和导出记录。
- 静态光影优先画在素材里，动态灯光聚焦少数重要点。限制同时可见的粒子和大面积半透明层，离屏详情暂停绘制，减少动态设置保留必要反馈。
- 独立原画要在相同光照、透视、像素尺度下设计，不同素材拼在一起仍须看起来属于同一个空间。
- 先以选定真实手机稳定30帧左右为测试目标；达不到时优先减少装饰、同屏层数与特效数量，不默认退回色块。此为待测目标，不承诺所有设备或60帧。
- 记录对象实际绘制间隔、触控到可见反馈、纹理和内存峰值、锁屏恢复及长时运行；桌面rAF与测试全绿不能替代真实TapTap观感。

## 5. 下一批只制作两个高保真运行样板

**样板A：同一星球的一处星雾。** 展示未探明、点击扫描、雾层翻卷/散开、真实地点出现与机器人靠近；同一镜头保留完整球体。提交同镜头三状态静帧与约15～20秒连续录屏。

**样板B：同一收据的整理与展示。** 展示托起、刷洗、压补、入柜、免费试一试与一句冷幽默。提交污损/清洁/修补对照与约20～30秒连续录屏。独立资产应在实际游戏渲染器中运行，不是视频贴图或PPT过渡。

两样板先用隔离数据验证美术/动作，不修改正式钱包、旧档或经济参数。通过后才扩展多雾、其他奇物、正式状态接入和后续星球。不额外开启新的大系统。

## 6. 验收顺序

1. **静态审美先过关**：360×800与390×844中的轮廓、色彩、物件比例、材质层次和球体完整度成立。即使暂停动画也不像占位草图。
2. **动作接触再过关**：正常速度下看得清工具如何作用于物体、雾如何离开地表、机器人如何取放；不瞬移、不穿模、不用特效遮掩。
3. **交互与真实状态对应**：玩家不用读长文就知道自己的动作产生什么结果；奖励/花费与既有状态一致。
4. **真实手机复核**：概念图与实际同镜头截图并排，明确保留了哪些设计、简化了哪些装饰。用户认可“达到这种感觉”后才形成可复制基准。
5. **工程回归**：旧档、已购权益、点击防重、维修/离线账目、星图无剧透、无强制操作仍通过；不以单测数量作为美术批准依据。

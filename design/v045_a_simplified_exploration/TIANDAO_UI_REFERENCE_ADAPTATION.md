## 2. 真正借鉴什么

| 可观察的参考特征 | 应用到失物星球 | 不照搬什么 |
|---|---|---|
| 暗色世界背景与浅色详情面板分层，打开面板仍能认出背景 | 主场景保留紫蓝星空；说明、设备、奇物操作采用统一可读面板 | 不全屏套亮白，不照抄仙侠花纹 |
| 屏幕边缘有图标加短标签，底部功能位置稳定 | 固定探索/收藏/基地；少量直接入口，位置不随昼夜乱跳 | 不增加两排侧边按钮，不恢复多系统占首屏 |
| 列表条目将图标、名字、等级/效果、按钮排成一致行 | 设备卡直接显示当前→升级后效果与费用；不再只写笼统的成长口号 | 不引入战力、种族、灵气、本源等数值系统 |
| 详情有明确标题、状态、主体和关闭位置 | 一个面板只处理一个对象；关闭回原现场；展开历史不再跳页 | 不学多层分页和嵌套弹窗堆叠 |
| 官方公告有主界面内出现的可互动事件 | 已有夜间访客、迷雾信号、发现物带位置标记，点击到对应详情 | 不新增免费刷币物，不把每个点都变成必须领取的资源 |

核心概括：**借世界中心和操作组织，不借系统复杂度；美术集中在星球、奇物和房间，UI不再像第二张概念海报。**

## 3. 对V0.4.5的调整，不重新推翻全部

已读取src/fusion/a-exploration.css及当前PR说明。现有三导航、一个目标、一个事件流已经成立，保留它们。当前CSS仍多处使用紫色渐变、金线、外发光，目标区、事件条、助力区纵向占位固定。优化重点是降低控件装饰竞争，释放画面，不恢复旧复杂入口。

### 3.1 探索首页：世界优先

候选布局（不是按字符比例实现）：

    顶部系统安全区：安静星空，不放按钮
    退货箱星 / 退件平原        零件         设置
    一行当前目标/当前工作（可展开）

             完整微缩星球
       机器人、飞船、局部雾和居民
       最多两个事件标记，位置贴近来源

    最新发现/正在发生的事             查看
    自动探索进度                     助力
    探索                 收藏              基地
    底部系统手势安全区

- 保持完整球体轮廓。常态先以主体约占安全可用画面一半为构图候选，再由360/390实图确定，不写死比例牺牲短屏。
- 长问题如“旧分拣站为什么夜里会自己开工？”缩为可展开一行“调查旧分拣站”。完整问题、来源及已知线索放入同一详情，不丢失有意义的下一目标。
- 常态只有一条当前事件摘要；无新事件时显示安静工作状态，不持续炫光。不把旧访客包装成新发现。
- 单独小设置入口保留在安全区内，避免静音/减少动态要跨两层找；星图仍从基地进入，不新增并列首页入口。原隐藏功能不删除。
- 助力改成紧凑但明确的主操作，不占满整排。候选触区至少48×48 CSS像素，标签不少于可读14px；最终按真实按钮文字与手机测量。连续有效输入仍反馈到机器人工作，不新增倍率、消耗或强制连点。

### 3.2 面板语言：深世界＋浅信息

- 世界保留原紫蓝、暖橙、黄铜、玻璃。UI外框以深靛/紫灰为主，浅纸灰/淡薰衣草色作为内容面，配深色正文，金色只强调主按钮、选中项或新发现。
- 不给每块面板加发光金边；移除多余荧光、双重描边、长条装饰标题。原藏品与玻璃美术不随这次UI变化重生成。
- 小信息用可关闭底部卡，费用/设备等中等信息用同一规格大面板；独立物品工作台继续全屏。不得同时叠观察卡、巡逻卡、工作台三层。
- 打开信息卡时要保留场景定位；不能为腾出文案把完整球体压成不可辨缩略图。展开完整详情可临时遮住部分场景，但关闭必须回原画面/滚动/选择，自动探索照常推进。点击穿透必须拦截。
- 关闭按钮固定位置；按返回先关当前详情。处理中关闭只离开视图，不取消已付款任务、不重扣；恢复显示真实持久状态。
- 具体进入/退出动效时间由真实样板决定，参考图不证明任何动画时长。

### 3.3 世界中的事件就是入口

- 既有白天线索、夜间纸影、弹跳空箱/纸蛾使用同一事件ID、来源坐标、真实时钟。图标＋短标签，如“灯下有动静”；未识别前不泄露名字和结果。
- 点击地表事件标记→突出其真实地点并打开该事件的短卡；不能先点“查看”，再找“线索”，再展开“靠近看看”三层才能看见动作。
- 图标与底部事件摘要指向同一事件，不另开巡逻/夜班/回放系统。未查看自动结束的结果在手记保留；再看是只读回顾，不重复发奖。
- 同屏优先一个主事件，最多另一个低优先提示；幕后/被遮挡的事件通过不挡主体的边缘指示或摘要进入，不强制新增球体旋转相机。
- 普通放置不点也继续，夜间不是打怪关卡。不添加随机碎片新收益来模拟对方玩法。

### 3.4 收藏、工作台与基地

- 收藏室完整艺术场景保留；一个简短收集计数。辅助藏品浏览用大缩略图＋名字＋物理状态，三列在小屏不可读时用两列；列表只是导航，不能替换六个玻璃柜。未发现物件不展示具体名字/外形，已约定的首星槽数不延伸成未发现星球列表。
- 点柜中物件或缩略图均进入同一个工作台。A/B/C整图、原价、真实提交后切换全部保留。未来美化材料也不能回退到污层/拼片生成下一态。
- 当前物件状态和一个主操作直接可见，如“清理 40零件”“升级 120零件”“轻按铃铛”；操作示例取现有规则，报价必须从模型读取。三态预览继续只读。
- 完成后突出一个代表互动和一句短梗；别用几段长说明盖住物品。来历/历史记录折叠。
- 基地主按钮候选改为直白“升级设备”，替代“让探索轻松一点”；卡片明确“机器人：每轮12.0→9.8秒”等真实模型差值。此数值只作版式示例，不能硬编码入游戏。
- 工程/科研/照料留在基地的次级区；所有已购买能力和效果可达，不因简化入口静默取消权益。

## 4. 手机安全区与交互约束

参考技术来源：https://webkit.org/blog/7929/designing-websites-for-iphone-x/ 。
- 顶部可只有星空，重要文字与触控避开摄像头、系统条和宿主覆盖控件。保留env(safe-area-inset-*)，核查viewport-fit及宿主是否已经内缩，避免重复padding。
- 现有fu-safe-sky使用max(36px, safe-area-top+10px)，先实测再调；不能全机型固定再加60px。环境回报0但仍有宿主遮挡时，要有经过真实测量的回退规则，不臆测设备。
- 目标360×800、390×844；大字、低高度、横竖恢复及底部手势区单独检查。文字保持可读，不为塞满所有东西降低到极小字号。
- 事件/按钮命中优先于球面助力；拖动、长按、滑动和关闭面板不能误增助力。夜间、限流、满队列仍按原规则。声音与减少动态尊重现有设置。

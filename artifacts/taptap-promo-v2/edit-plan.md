# v2实际剪辑

主题为一套具体流派的组合结果，片长54秒。画面以实际战斗和实际选卡推进。

| 时间 | 镜头 | 主字幕 |
| --- | --- | --- |
| 0～4秒 | 雷暴蜂群、星环奇点与精英战的高火力钩子 | 把电网装进蜂群，会怎样？ |
| 4～8秒 | 基础主炮小飞船 | 出港时，还挺乖。 |
| 8～10.5秒 | 普通新局实际选择电弧线圈 | 这局，试试放电流。 |
| 10.5～14秒 | 新获得的电弧开始参与攻击 | 同上，13.6秒退场 |
| 14～19.5秒 | 点击星链雷网，恢复战斗 | 先把电弧，铺成网。 |
| 19.5～25秒 | 雷暴蜂群融合确认与实际展开 | 再让蜂群，把电网带走。 |

| 34～48秒 | 追加星环奇点的连续敌潮与精英战 | 40～42.7秒短暂出现“再塞一颗黑洞。” |

4～14秒标为普通开局，0～4秒及14～54秒标为进阶配装演示。34～54秒保持父版原二十秒连续实操，最终文字出现期间战斗继续。

选卡时主字幕位于卡片、按钮和配方说明下方，战斗时回到主角下方。白字与暖金重点、深紫描边和短弹出继续沿用。封面采用本版49.2秒的实际战斗底片，主标题为“会追踪的电网？”。

配乐《Relay Chase》144 BPM，四拍底鼓、八分低音、十六分踩镲、琶音与失谐合成器共同构成推进感。19.5秒起短暂收束，21.3～22秒军鼓滚奏，在实际融合确认附近22秒落拍，34秒后进入最高强度。48秒减少主旋律密度，保留节奏承接片尾，最后0.7秒淡出。

同期游戏音效保留原时点。配乐通过轻度侧链压缩为明显的武器和融合音效留空间。全部画面以1倍速度剪辑。

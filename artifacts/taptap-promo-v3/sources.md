# v3 真实来源

沿用v2提交`ad8efd0`的54秒真实游戏剪辑。此版只更新文字字形、层级和字效；没有补录或生成战斗。

4～14秒来自普通新局，其余是已注明的合法进阶配装实操，捕获源码`4ba48981fa2b63ed6e26ebc5f658a92cc643a9a5`。镜头、音轨和来源标签的完整解释见[父版来源](../taptap-promo-v2/sources.md)。

字体从[官方v2.0.1发布](https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1)取得，随本仓库保留原始TTF、OFL许可、下载包与字体文件SHA256。字效代码只处理渲染层，不修改字体文件。

本版直接复制v2成片AAC流，同期武器声音与144 BPM原创配乐均保留。`sources.json`记录所有本版输入摘要。封面仍为同一实际49.2秒底片。

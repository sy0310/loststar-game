# v3 字体修改时间线

沿用v2剪辑及字幕内容，保持54秒，改变字体与字效层级。

| 时间 | 文案／画面 | 字体处理 |
| --- | --- | --- |
| 0～4秒 | 把电网装进蜂群，会怎样？ | 两行粗斜金色标题，“会怎样”加大，短弹出 |
| 4～8秒 | 出港时，还挺乖。 | 白色粗斜短句，轻紫色侧影 |
| 8～14秒 | 这局，试试放电流。 | 同字形短句；选卡时放到底部空位 |
| 14～19.5秒 | 先把电弧，铺成网。 | 金色重点短句，保留配方与选卡文字 |
| 19.5～25秒 | 再让蜂群，把电网带走。 | 同上，随实际融合恢复战斗 |
| 25～34秒 | 打一架，电一串。 | 金色短句短暂出现，随后让画面继续 |
| 34～48秒 | 连续战斗；40～42.7秒出现“再塞一颗黑洞。” | 左下小标题，避开黑洞主体与摇杆 |
| 48～54秒 | 片名、TapTap提示、下一套配装提问 | 两行游戏字标，信息小字清楚，CTA同字形 |

普通开局与进阶配装标记保留，所有实际游戏HUD保持完整。音轨直接复制v2，未重新混音。原封面与新封面使用同一49.2秒战斗底片以供比较。

# 《失物号：星海生存》v0.6 原创像素肉鸽 H5 Demo

> 2026-11-11 用户已明确决定：**以吸血鬼幸存者式360°生存战斗取代原“选航点—拼舱—返港—黑市”的主玩法**。重点让人“一指移动，打一把爽一下”。本目录是首个独立可玩原型，**不是 v0.5.1 的正式替换包/正式发布**。

## 直接试玩

一个 `index.html` 包含 Canvas、CSS、JS 与所有临时像素精灵，可离线双击运行。推荐在本机独立目录启动：

```bash
cd prototypes/salvage-survivor-demo
python3 -m http.server 4397
# 同一台Mac另开终端：
open http://127.0.0.1:4397/
```

不能把 `4397` 当作本次工具已经替用户启动的 Mac 服务。**原Mac `4283`、TapTap开发自测`469033`不变**，直到Codex在用户Mac上完成真实安全部署。

## 操作

- 手机：按住游戏画面并向任意方向拖动，出现浮动摇杆；飞船朝摇杆方向自由移动。
- 键盘：WASD/方向键；`P`/`Esc`暂停。
- 武器自动寻找敌人攻击，拾取经验晶体后升级三选一。
- 预计一局3分钟，70秒精英、130秒Boss，死亡或存活结束均可结算并“再打一把”。

## 实际实现内容

- **360°世界自由移动**、平滑跟随镜头、四方向来敌、连续自动攻击，不是纵向固定朝上射击。
- 6主动：脉冲主炮、追踪无人机、电弧、震荡导弹、旋刃护卫、离子护盾。最高Lv3。
- 6被动：聚能透镜、锁定芯片、超导电容、冷却矩阵、回收磁场、反应装甲。最高Lv2。
- 主动Lv3 + 指定被动Lv2有6种可主动选择的EVO（贯星轨炮、猎手蜂群、星链雷网、彗星弹幕、磁旋收割阵、反应壁垒）。
- 双主动Lv3可主动选择2种融合：无人机+电弧→**雷暴蜂群**；导弹+旋刃→**爆裂刃环**；融合后释放主动槽。
- 5类普通／特殊敌人，包括会发弹的远程机、耐打矿机、70s精英、130s Boss，经验/零件掉落、弹幕/爆炸/电链/护盾。
- 游戏内少量长期强化：只属于独立 Demo 的船体、主炮等级，不读取/修改原游戏资金、欠款、飞船、任务、装备或存档。
- 主循环没有节点选择、燃油返航、货舱拼格、NPC黑市、付费服务、广告。

## 已完成的真实浏览器测试

- Chromium headless：360×800及390×844，游戏启动、单指/鼠标拖动、三选一卡、六级满级操作、双主动融合释放原装备槽、主炮+被动进化、暂停恢复、结算重开，0 pageerror。测试保留在 `qa_survivor.py`。

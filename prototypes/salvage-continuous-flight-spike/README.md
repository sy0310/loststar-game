# 《失物号 · 星海突进》独立武器联动 Demo 0.1

> 这是用于验证“持续飞行、自动射击、武器联动与再开一局意愿”的 **H5 原型**。不是 v0.5.1 的替换版本，也不读取或修改《失物号：星海拾荒》正式试玩的存档。

## 立即试玩

解压后双击 `index.html` 即可在 Mac / Windows 的现代浏览器中直接玩。手机可以把解压目录放入任何静态 HTTP 服务器访问；此 HTML 无第三方依赖。电脑上使用鼠标按住拖动，或方向键 / WASD 移动；手机直接用手指拖动飞船。武器自动开火。P / Esc 或右上角按钮暂停。页面切后台、锁屏会自动暂停。

## 核心玩法（这一版已能玩）

- 持续纵向飞行、自动主炮、星空滚动；3类小敌人（追逐小无人机、横移炮手、矿石残骸）和一类精英守卫。
- 打掉敌人拾取零件、经验和少量稀奇物；升级时 **三选一**。最初就有主炮，之后可以拿无人机、电弧核心和护盾，所有装备最高三级。
- **武器联动是可运行代码**：
  - 主炮＋电弧：`雷光齐射`，主炮命中会连锁电击相邻敌人；
  - 无人机＋电弧：`雷暴无人机`，追踪弹落点再放电；
  - 护盾＋电弧：`放电反击`，抵挡伤害时释放电弧；
  - 主炮＋无人机：`协同锁定`，主炮留下短暂标记，追踪弹攻击带额外伤害。
- 每90秒首次出现折返结算，之后继续飞可在更深阶段再看到折返；不会因返回距离扣更多燃料。
- 结算后可使用本 Demo 的零件永久小幅强化主炮与船体。采用独立 `loststar.flight-spike.prototype.v01` localStorage 命名空间，旧 Demo 的款项、升级、货物和任务永不读取。

## 可试玩但未达到正式产品要求

- 飞船与敌人均为 **原型程序绘制像素**，还未替换为正式美术资源。
- 本版只验证“飞行是否比节点探索更想玩下一趟、联动是否能辨识”；尚未整合B＋C货舱、黑市、四艘船、原有剧情、正式存档和广告。
- 普通短局的帧率/手机发热/真实TapTap WebView体验未作实机验收；开发用 Playwright 控件测试和加速节奏检查不能替代玩家体验。
- 没有接入原 Mac `127.0.0.1:4283`、没有上传 TapTap，也没有修改原 `v0.5.1 / 469033`。

## 演示 QA（可选）

浏览器访问 `index.html?qa=1` 才会暴露 `FlightQA` 测试钩子。测试钩子用于隔离调试，不会接触旧档，普通玩家不会看到。测试已覆盖 360×800 / 390×844 竖屏下升级、实际双装备联动、折返、结算、重开、暂停以及页面错误日志。若只从 `file://` 直接打开，仍可正常游玩，不需要网络。

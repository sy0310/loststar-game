## 几何、材质与唯一运行通路

固定光源为左上暖光，深紫搪瓷与黄铜，统一3/4像素视角。逻辑面192×192，对应原生384坐标。独立PNG保留作者原坐标；运行WebP最长边384，`part(raw)`必须显式恢复原生绘制尺寸后再套源坐标矩阵。杆轴原612×225，不能把压缩后的384×141当成原坐标。

胶带后孔(136,120)、卷孔(237,137.15)、前孔(295,147)同轴，前后支承及轴帽来自真实独立源。轴/壳/卷外轮廓固定，卷绕标记相位随出带长度/物理半径推进。只有一条连续实体带；前后两个深度区域仍是同一带的同一光栅，不是叠加纸条。带纹只在176×202的小区域量化缓存；纹理UV不采图集透明边距，避免连点时形成断带。A的粘灰沿真实扫线去除，B仍有松带，C张力与导向稳定。

铃固定壳、孔后圈、滑杆、孔前圈、螺钉分别登记。帽+恒长杆干净独立，不带铜壳截图；杆进入固定孔面的部分遮挡，完成态螺纹藏入孔后。顶帽接触面native(198,76.5)，轴native x198/孔心y130.5；指腹接触才压，触底保持窗口0.65–0.80秒才触发，余音独立衰减至1.8秒。空闲时顶杆不漂动。

两者统一使用 `src/fusion/curio-mechanism-model.ts`、`curio-mechanism-renderer.ts`；房间、工作台、0/I/II与六张PNG从同一物理命令/材质映射生成。旧blankPaper、完成图裁块bridge、带紫壳的螺钉截片不再进入玩家解码/绘制；旧源仅作历史。I/II的10%工程省料、7→5工时与全部存档权益未改。

## 可复现导出与审核边界

顺序执行：

```sh
node scripts/export_mechanisms_v042_static.mjs
node scripts/export_mechanisms_v042_contacts.mjs
node scripts/export_mechanism_deposits_v042.mjs
node scripts/export_mechanisms_v042.mjs
```

`static-registration.json`是静态作者装配资料，不能当作运行验收；`registration.json`记录实际候选运行素材、六态、WebP字节/尺寸/hash以及审核阶段。Root已进行390原生密帧内部预审；最终统一源码包、完整回归和TapTap手机视觉审核仍由root交付，测试通过不等于用户美术验收。样板静态390合成图不是真实手机截图。

本批仅胶带/铃。现代单张收据与其他三物不重画；存档、货币、费用、奖励和业务模块不在本批修改范围。

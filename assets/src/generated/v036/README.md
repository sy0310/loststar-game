# V0.3.6 原创星雾候选

本目录是内置 OpenAI `image_gen` 为两个隔离运行样板制作的原创素材来源。三层星雾独立导出为 RGBA WebP，在同一真实球体渲染器上组合。

前两轮生成时仓库尚无《失物星球探索流程概念图.png》和《失物星球_奇物修复展陈方案.png》两张已认可概念原图，因此只按实施文档和自有球体素材制作候选。两张原图随后真实导入 `design/v036/reference/`，第三轮星雾与工作台均在实际查看原图后以其为风格参考重新生成。当前运行素材仍待实际合成及用户动态审核。

## 源与选型

- `star-fog-layers-v1.png` 为第一轮三层云团。质感候选保留，但轮廓过扁，难以遮住实际分拣机高部。
- `star-fog-layers-v2.png` 保留第一轮材质与色彩，改为高圆顶轮廓，但下缘存在硬水平截线。
- `star-fog-layers-v3.png` 直接参考已认可探索图，保留圆卷暖缘与少量星尘，改成不规则薄雾卷边。当前运行层从此图导出。
- `restoration-workbench-v1.png` 直接参考已认可修复图，制作独立空白工作台，带紫色台面、暖金灯和边缘工具环境。原稿上窗出现参考中的天体，被自检排除。
- `restoration-workbench-v2.png` 精准去掉上窗天体，只保留星空和室内。当前运行背景从此图导出。
- `prompts.json` 保留各轮实际提示词和输入角色。

星雾源图均为1024×1536 RGBA，三层分别位于上、中、下512像素行。源图自带透明边界，未以黑色键控抠图。工作台为独立绘制的1199×1312 RGB背景，不含纸、工具、机器人或文字。未复制其他游戏美术，也没有将概念海报直接当作场景。

首帧合成检查发现的v2水平截线已在v3源中改为薄雾与卷边。散雾方向、实际遮挡和地面接触仍由运行样板审核，不能只凭源图标记通过。

## 重复导出

```bash
node scripts/export_v036_assets.mjs
```

每行裁切后按最近邻等比缩至256×128，再添加上下透明空间，输出共用256×192画布，接地锚为 `(128,170)`。没有非等比拉伸。工作台等比覆盖缩放至640×700，中央纸脚锚为 `(320,490)`，台面范围y438–535。三层星雾与工作台共709,406字节，导出记录包含源和运行素材SHA-256、实际透明边界、锚点与光向。

将背雾略提高、前缘略放低可以形成包围高建筑的体积，主雾保留等比圆顶。扫描阶段应沿局部光路揭开遮罩，再让各层独立翻卷散离。不能把三层同相位整体平移，也不能只做整团淡出。

## 接触工具复用

已检查原始 `assets/src/generated/v034/restoration-tools-v1.png` 和受损纸张。刷毛与刷柄、托盘、刮铲已有独立透明材质和接触锚，适合复用。新样板将改动作路径和真实接触，避免额外复制一套工具来源。

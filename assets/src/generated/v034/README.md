# V0.3.4 出土修复素材候选

本目录保留内置 `image_gen.imagegen` 制作的原始PNG、完整提示词和纠错版本。本轮包含同一件出土收据的分层材质、三个既有居民各两帧白天动作，以及三种夜间异常的设计分镜。主线程独立审核原图、原生比例合成和实际Canvas，玩家视觉审核仍待进行。

## 同一原件的三个物理状态

原型沿用 `receipt-inner-blank-v1.png` 的倾斜长纸卷、右上铰点、米纸明暗和右下卷边。`receipt-paper-damaged-v1.png` 增加真实透明破口与纤维断面，作为S0、S1、S2共同的纸体。

| 状态 | 分层内容 |
| --- | --- |
| S0 出土污损 | 破损纸体、固定原墨、独立泥层 |
| S1 已清洁 | 相同破损纸体与固定原墨，刷除泥层 |
| S2 已加固 | 后补纸、相同破损纸体、固定原墨、前补纸纤维与胶沿 |

`receipt-surviving-paper-mask.webp` 由共同破损纸体的原alpha导出。三个状态的字码均裁切到这个相同存留区域。样板固定码为RET-031、P03和签收空白线，具体排字由renderer实现。补纸只提供无字支撑面，原来缺失的笔画持续缺失。

## 候选与退回记录

- 破损纸体保留原纸身份，左上破口与左下裂口已获准进入实际合成。
- 泥层v1的高分辨率颗粒偏照片，源预览有红黄色透明边色。主线程要求返修。v2改为更大的像素土粒、干裂块和刮沟，实际alpha合成中的可见红黄越界颜色数为0，已获准进入renderer。
- 补纸v1大而淡，67px审计中修补变化不足，主线程退回。
- 补纸v2改成两条窄带，几何已符合修补方式，自审发现胶沿仍过弱。
- 补纸v3保留窄带结构，重画更清楚的琥珀胶沿、透明纤维内芯。实际主轴尺寸为35×8.147和26×8.865纹理像素，保持原撕口可见。当前材质opacity为0.75。主线程已查看同组实际合成与Museum S2，批准进入本轮候选录制。胶沿仍稍亮，接近细金属夹的材质观感，保留给玩家审阅。

每轮源图都保留。正式候选的选择写在 `registration.source.json`，可重复导出。

## 注册契约

所有上纸层共用256×256画布、中心(128,128)、铰点(186,48)、卷边根切线y190。共同纸体的可见alpha16包络为(35,9,187,239)。

`assets/runtime/v034/registration.json` 的 `receipt.layers` 提供 `paper/mud/patchBack/patchFront/survivingMask`。后补纸与前补纸由同一新窄带源图按存留纸面alpha分区，源纹理颜色和自然比例保留。

补带按源图主轴等比注册，主带跨左上缺口，副带横跨左下裂口。`receipt.patchPieces` 记录源区域、实际主轴尺寸、统一缩放和目标中心。`receipt.patchTargets.upper/lower` 的 `srcRect` 为实际alpha区域，`contact` 按补带与存留纸面共同alpha加权，机械夹可按在有原纸支撑的粘接处。`bridgeCenter` 是整条补带中心。

## 出土前土与工具

独立土层有清楚土粒、压实层理和中央低口。`soil.back/front` 由同一土层源图分出，保持共同512×99坐标，完整重组保留原土体。其 `paperRelative` 为同镜头审计位置，前土能遮住正在升起的收据下沿。`soil.complete` 供整体土层与分层结果对照。

托盘和刷子来自独立工具源图。导出裁切到真实工具区域，排除源atlas上方的杂alpha白带。

- 托盘为384×108，接收点约(190.588,53.530)，前唇切线y77.009。实际renderer优先把这个接收点对齐柜内真实receiverY，审计 `paperRelative` 记录局部布局。
- 刷子为192×163，软刷接触点约(34.252,144.819)，木柄支点约(159.948,31.346)。建议完整刷宽约18世界像素，接触点用于按纸面定位与旋转。

纸可由已有机械夹托举离土，托盘与土层以真实接收面定位。托盘图和纸体图保持独立。

## 导出与审计

```bash
node scripts/export_v034_assets.mjs --audit
node --check scripts/export_v034_assets.mjs
```

脚本对原图做统一最近邻注册、源部件等比裁切、透明分层与lossless WebP导出，开启 `exact:true`。所有绘画内容来自内置生成原图，alpha遮罩与前后分区由同一原图确定。

`audit/receipt-stages-registered256.png` 的四列依次为土中升起、S0、S1、S2，摄像机与原件注册一致。`receipt-stages-native67-4x.png` 先按67px纸高合成再放大。`mud-v1-v2-registered256.png` 保留退回版与新版的实际覆纸对比。

`audit/export-audit.json` 记录导出脚本、源注册表和全部运行时文件的SHA256、体积、居民实际包络，以及异常标准稿的alpha审计。重复运行不会写入时间戳。

## 三居民白天动作

每种新增两帧，共用256×256透明画布与足点(128,244)。同种两帧使用一个等比最近邻缩放，每帧按实际支撑脚点注册，保留蹲姿变矮、眼柄伸出和低头的形态变化。`registration.json` 的 `residents[id].frames` 提供 `file/contact/displayScale/visibleBounds`。运行时只应用一次 `displayScale`。

| 居民 | 两帧动作 | 实际可见逻辑尺寸 |
| --- | --- | --- |
| 拆封鼠 | 低头嗅地上纸屑、坐起举纸啃咬 | 83.09×63.97、81.00×73.01 |
| 箱寄居蟹 | 伸眼探头抖壳、螯将小纸拖近 | 60.28×62.62、59.24×60.28 |
| 标签鸟 | 落杆看翼上标签、低头啄签 | 46.67×49.66、46.67×46.45 |

鼠的两帧表达嗅闻与进食两个阶段，适合在停顿阶段选择。快速来回切换会让蹲坐跳变过于明显，动作时序由主线程审核。蟹保持原纸箱、封带、回转箭头和绿叶身份。鸟的翼签、护目镜随头颈动作保持相连，脚尖对齐实际栖杆。

三张旧day素材保持原自然比例，注册记录原真实 `dayContact`。旧鸟画布按47宽等比绘制时高43.70，本次动作候选可见高约49.66，保留核心身体宽度的尺寸选择由实际场景审核决定。

鸟原PNG有大面积alpha1的灰白预览边色。导出仅清除alpha小于16的像素，alpha16及以上的原颜色与透明度完整保留。所有原PNG保留，实际透明边以棋盘合成为准。

`audit/resident-daily-native.png` 三行依次为鼠、蟹、鸟，每行三列依次为旧day、新动作0、新动作1。它先按实际逻辑比例合成，`-3x.png` 再最近邻放大。主线程已查看原图，后续独立复审实际Canvas中的足点、体量和动作节奏。

## 三异常形态与动作标准

`anomaly-standards-v1.png` 是3×3设计分镜，三行依次为漂行纸影、弹跳空箱、环灯纸蛾。每行三格提供动作轮廓与设施响应的候选。

- 纸影沿用旧紫色纸箱、浅绿眼孔与封签身份，展示侧片展开、光束核验、侧片贴体收拢。
- 空箱具有真正空腔和外翻封条，展示箱壁压缩、回弹跳起、隔离门前遮挡。它与有肢体和绿叶的居民蟹有独立轮廓。
- 纸蛾采用米色双纸翼、暗红邮签纹和细触须，展示上扑、下扑扰灯、折翼离灯。

标准稿含局部灯具、光束和动作轨迹，用于设计审核。正式动画需独立分层、共足点或铰点制作。当前正式纸影主事件继续复用已验证原资源，空箱和纸蛾的完整玩法尚待后续批准。

`audit/anomaly-standards-dark.png` 使用真实alpha暗底合成，清除alpha小于16的预览边色。可见区域的强红越界颜色统计为0。纸影第三格的折叠幅度仍较克制，需在后续正式分层时明确侧片铰链和收拢路径。

这些是素材合成审计。完整出土、刷洗、压合、居民作息和球面夜间事件由主线程在实际Canvas连续运行验证，手机表现由玩家实机审核。

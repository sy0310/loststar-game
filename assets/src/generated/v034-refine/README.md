# V0.3.4 修复动作与比例精修素材

本目录保存内置 `image_gen.imagegen` 的五张原始PNG、完整提示词、返修记录、坐标源表和原生比例审计。主线程独立审图，当前选中补纸v3与薄铲v2，进入实际接触动作预审。上背贴在静态67px对照中仍偏弱，最终可读性取决于翘角、压合和露背的实际运行合成。

## 共同纸体与补纸

补纸共用256×256坐标，纸体、字码和缺失遮罩引用同一份V0.3.4原件资源。源纸可见高度239纹理像素，实际显示纸高约67逻辑像素。补片具有独立真实纤维面与折边，后层在原纸后绘制，前层保留柔软折边和局部纤维。所有材质alpha已导入WebP，运行时 `opacity` 为1。

| 部位 | 实际纹理包络 | 压合点 | 受力点 |
| --- | --- | --- | --- |
| 上缺口背贴 | x69、y58、宽20、高34 | (84,62) | 原纸右上铰点由纸体rig负责 |
| 右下卷根补纸 | x156、y197、宽36、高16 | (166,203) | 卷根(156,204) |

压合点取自原纸与补片共同存在的实alpha像素。上片跨过原撕口轮廓，灰米／淡紫纸背与暖桃色原纸有材质差别。下片承接卷根，末端舒展由共用纸体rig控制。原字码按存留纸面遮罩绘制，补片没有印刷内容。

早期补纸v1在原生尺寸中与纸面混在一起。v2只调整下片膜面面积，保留为中间稿。v3增加偏竖上背片、下片折边和灰紫纸背色差。主线程认为下片可辨，上片需结合真实动作继续审核。

## 工具与土块

软毛刷复用原图，按真实刷毛根部拆成两张同注册透明层。两张均为192×163，共同支点(85,101)，刷毛接触点(34.252,144.819)，木柄握点(159.948,31.346)。重组检查中，alpha16以上通道差异为0，部件重叠像素为0。刷毛压缩可围绕共同根部进行。

薄托纸铲v2为256×210，真实薄刃接触点约(24.352,203.469)，木柄握点约(215.687,33.265)。建议全宽16.5世界像素、高约13.54。完整宽度低于原件实际可见纸宽的三分之一。v1软椭圆刀面在原生尺寸中识别不足，v2增加平直刀面、深色薄底与更清楚的铜箍。实际接触动作仍由主线程审查。

四块土屑来自原土层真实RGB纹理。导出用人工核对的原岩块轮廓裁切alpha，记录来源区域与纹理哈希。每块落地点使用实际最下方alpha行的像素中心，转动中心独立记录，便于重力运动与落影定位。

## 运行与审计

```bash
node scripts/export_v034_refine_assets.mjs --audit
node --check scripts/export_v034_refine_assets.mjs
```

脚本使用等比最近邻注册、真实原图裁片、透明层分区和lossless WebP导出，开启 `exact:true`。原始PNG完整保留，选中版本写在 `registration.source.json`。`prompts.json` 保存每轮完整提示词、参考、生成原路径和审核状态。

`audit/receipt-s1-old-s2-new-s2-registered256.png` 三列依次为S1、旧S2、本轮S2。`native67-5x.png` 先按约67px真实纸高合成，再最近邻放大。旧补片按旧注册中的材质opacity绘制。

`audit/bird-day-rest-flight-old-new-native-3x.png` 九列依次为旧day、两夜栖、两巡飞、两旧比例啄签、两新比例啄签，使用同一落脚线。`brush-spatula-on-paper-native-6x.png` 按工具建议尺寸叠到原生纸面，提供材质识别对照。上述审计是素材合成，完整受力与接触表现以实际Canvas连续运行审核为准。

`audit/export-audit.json` 提供导出器、源表、运行文件、五张原PNG和所引用旧资源的SHA256与体积，重复导出使用同一确定性输入。

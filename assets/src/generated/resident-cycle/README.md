# 三居民昼夜姿态素材候选

本轮为拆封鼠、箱寄居蟹和标签鸟各制作两帧夜间姿态，并为标签鸟补充两帧白天巡飞。四张原始PNG均由内置 `image_gen.imagegen` 基于本项目原居民精灵重绘，完整提示词保留在 `prompts.json` 与 `tagbird-flight-prompt.json`。原始昼间精灵继续作为身份、色调和像素密度的参照。

主线程已审看四张原图、六帧休息的原生尺寸审计与两帧巡飞的原生尺寸审计，身份、造型与体量可进入实际Canvas球面审核。连续运行和用户手机审核待完成。

## 姿态与取舍

| 居民 | 原身份特征 | 夜间实际造型 |
| --- | --- | --- |
| 拆封鼠 | 大粉耳、奶油毛色、额头护目镜、紫卷尾、橙色邮包 | 侧蜷低坐，闭目抱纸屑，脸颊靠近纸团，双腿与尾巴收在身体旁；第二帧胸肩和耳朵轻抬 |
| 箱寄居蟹 | 橙纸箱、白封箱带、绿叶、紫色返件箭头、紫足与青金眼 | 大螯收回箱内，壳底只露小眼和支撑趾；第二帧一眼略开、箱盖与叶尖轻动 |
| 标签鸟 | 米纸羽层、红标签缝线、铜护目镜、紫尾、棕爪 | 收翼圆身，头喙藏入翼下，尾羽折拢；第二帧羽层随呼吸略抬 |

标签鸟保留了一部分亮蓝护目镜，主线程允许在原生夜色下评审其警戒含义。最终循环可按实际画面决定栖息与观察的节奏。

额外的 `tagbird-flight-v1.png` 是同一鸟的抬翼和下扑两姿。双脚收入腹下，头身位置一致，标签翼、紫尾和羽层具有实际扑翼轮廓。巡飞最大翅展约为原站姿宽度的1.42倍，核心头身按原鸟体量评审。

## 足点与尺度

八帧运行纹理统一为256×256，接触点为(128,244)。每一物种的两帧共享同一个原图到纹理的等比例最近邻变换，呼吸造成的原生形变会保留。

| 居民 | 白天原图足点 | 白天自然逻辑尺寸 | 夜姿可见逻辑尺寸 |
| --- | --- | --- | --- |
| 鼠 | (120,276)，源256×276 | 83×89.484 | 79.266–79.961×55.973–57.016 |
| 蟹 | (116,257)，源256×258 | 66×66.516 | 61.839×51.446 |
| 鸟 | (116,238)，源256×238 | 47×43.695 | 41.992–42.383×43.750–44.727 |

昼间足点从前脚或栖爪的支撑基线量取。蜷睡鼠使用含尾部的身体支撑基线中点，缩壳蟹使用壳下支撑基线。它们在原图中的坐标与定义保留在源注册文件，可根据真实球面接触进行可逆微调。

飞行两帧使用共同虚拟足位，作为躯干下方的统一运动锚点。抬翼帧可见尺寸66.656×44.156，下扑帧64.688×52.875逻辑像素，下扑翼尖会低于虚拟足位约2.5逻辑像素。

`assets/runtime/resident-cycle/registration.json` 的顶层 `residents` 以 `mouse/hermit/tagbird` 为键。每项给出 `dayContact` 和 `frames`，标签鸟还含 `flightFrames`。每帧提供文件名、接触点、可见alpha包络、原始格坐标、原始足点、显示比例和字节数。

绘制时将接触点转换到世界足点，再按 `displayScale` 统一放大整张256画布。`scaleRelativeToDay` 是已编码可见宽相对白天名义宽的审计比例，显示时使用 `displayScale` 一次。

## 导出和原生尺度审计

```bash
node scripts/export_resident_cycle_assets.mjs --audit
node --check scripts/export_resident_cycle_assets.mjs
```

脚本以真实足点作同一等比逆向最近邻采样，保留源RGBA。导出采用lossless WebP和 `exact:true`，保存透明像素通道信息。六帧夜姿合计367798字节，两帧飞姿合计116410字节，总计484208字节。

重复执行导出后，八张WebP与注册文件共九份输出的SHA256全部一致。实际比较记录保留在 `audit/export-reproducibility.json`，其中同时记录导出脚本与源注册文件的哈希。

`audit/resident-day-rest-native.png` 为三行鼠、蟹、鸟与三列白天、夜0、夜1的真实逻辑尺寸审计。金色线标记支撑基线。`-3x.png` 为同一像素结果的最近邻放大。`audit/tagbird-day-flight-native.png` 给出站姿、抬翼和下扑，`-4x.png` 为放大版本。

这些审计检查身份、尺度和接触注册。实际390px球体场景中的光照、遮挡、呼吸节奏、栖点与飞行轨迹，由主线程连续运行验证。TapTap真实手机上的最终可读性与后台恢复仍待复测。

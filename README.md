# 失物星球 · Lost Planet

像素风 2.5D 微缩星球放置探索游戏，面向竖屏 H5。

> **特色钩子**：你的飞船会自动探索怪诞星球，每次回来都带回一些完全搞不懂用途的宇宙奇物。

**当前状态：设计稿审阅 / 技术规划，尚非游戏成品。**

- 游戏循环：未知星域雷达扫描 → 发现星球 → 飞船降落／环绕 → 机器人自动探索 → 奇物／生物收集 → 基地展示和设备升级。
- 美术：高像素密度、统一材质、2.5D／伪 3D 微缩球体；轻量化不等于低分辨率。
- 关键约束：星域内所有未发现的星球，数量／名称／位置／剪影均不得提前展示。
- 首颗星球：退货箱星（退件平原）。
- 内部内容规划：六个可矩阵式扩展的生态主题，但玩家开局不可获悉。

详细设计规范、设计稿索引、Codex 执行说明见设计分支中的 `docs/`、`design/` 与 `codex/`。

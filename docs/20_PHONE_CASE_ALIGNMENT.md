# V0.2.3：按手机反馈校准展柜与台架

本轮延续 [两项P0重构](19_P0_HOME_WORLD_REVIEW.md) 和 [Review 5747890495](https://github.com/sy0310/loststar-game/pull/2#pullrequestreview-5747890495)。用户在 TapTap **424659 / 0.2.2 / 14cc368** 实机确认“有走动”，同时指出玻璃框与摆放架不对齐；昼夜挂机观察尚未回报。这里明确记录实际已确认的范围，不把“有走动”扩写为所有动画/昼夜都通过。

## 原因与修正

320×320透明素材单元的中心不等于柜体中心：例如胶带容器实际基座中心x137，套娃容器x193，直接按x160对齐会左右错开。部分前玻璃还包含一个与背层高度不同的底座，叠加后产生双台座；旧通用物品位置/尺寸也使胶带或宇宙包裹超出玻璃。

新增 `src/render/museum-layout.ts`，逐件测量并保存：房间实际台面落点、背层基座中心/底边、有效精灵范围、玻璃内腔、前反光窗口、藏品中心和尺度。运行时使用这些实际像素锚点，不编辑原始设计参考，也不重新生成另一套房间。

- 六个柜体基座分别落在 `(175,526) / (389,526) / (606,527) / (156,774) / (389,774) / (622,774)`，对齐背景六个椭圆台面，宽度适配台面，铭牌同源定位。
- 实体框架、盖与底座只绘制一次，来自背层原图；前层仅取已注册的透明玻璃/反光窗口，映射到对应内腔，不再叠第二个不同基座。裁掉素材单元边缘无关残片。
- 六件藏品按各自内腔缩放、居中，并在真实玻璃窗口内裁切；保留六种独特循环。前排高柜缩放后不会盖住后排铭牌。
- 机器人取放、手持尺寸插值和开罩接触点共用这份布局，首页、近景收藏室和升级对照也共用；不额外维护另一套展柜坐标。

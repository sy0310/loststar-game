# V0.3.8 远征反馈返修

依据PR #2的2026年11月5日实机反馈，本轮集中修正机器人助力动作、星雾尺度及重复分拣设施。运行基线为TapTap 435439 / b7f7326，代码与证据基线为213f2a7。

## 助力动作

机器人路径、步态与扫描摆扫采用同一实际探索工作积分。被接受的输入触发短促的眼灯和手部应答，实际消费助力时步频随路径一起加快。拾取与卸货保留接触、搬运、递交和松手过程。

触点回应、机器人收到指令、已消费工作和真实卸货分别记录。经济参数沿用当前模型，拒绝输入和夜间关注依各自状态显示。

探索触控区域及其子元素设置透明系统点按高亮，键盘使用可见焦点。该属性控制浏览器点按高亮的行为，手机蓝闪的具体来源仍结合本包实测判断。[MDN说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-tap-highlight-color)

## 区域星雾

以原三张分层美术制作同镜头尺度候选。旧宽度为94、122、220，新候选为156、196、274逻辑像素。图层分离、接触阴影、反光、显露孔、球体支持遮罩和点击像素一起调整。最终取值依据实际360×800与390×844构图确认。

三处真实锚点、种子、揭晓时间和工作进度直接读取现有周目。动态Canvas点击遮罩随显露孔版本更新，在发生命中读取时重算。

## 单一分拣设施

核对原球图、基础实体及融合扩展层。原球图包含纸箱地貌、管线和后缘雷达。基础层旧分拣机位于568、294，融合层的真实任务机位于410、315。

融合周目采用410、315的同一分拣机实例，承接废旧、卡纸、施工、完工状态与P03/P30。原灯位改为轮廓明显不同的细安保灯架，灯头559、208与夜间引导光源共用注册。

## 开发所需资产（Codex/美术须制作）
- 球体层：星球基体、底层阴影、可绕轨前后遮挡、不同区域地貌。
- 地表：至少一个仓库、纸箱 3–5 种、退货标志、传送带、旗帜、卫星天线、植物与岩石。
- 机器人：待机、行走、扫描、拾取、返回/卸货（透明帧、锚点一致）。
- 飞船：巡航、背面、正面、引擎喷焰、着陆与停靠参考角度。
- 生物：拆封鼠的至少待机/移动/拆箱动作，后续可复用模型处理其它生物。
- 奇物图标：收据、道歉胶带、套娃包裹、收件人宇宙包裹等，带清晰描边。
- 雷达：扫描扇区、信号波、锁定反馈、揭晓光效。
- UI：可读中文字体、按钮/禁用/高亮/图鉴卡片/弹窗/进度条资源图标。
- 场景和 UI 所有生产素材都须有来源与授权字段，并保留可修改源文件。

## 素材命名和格式建议
assets/src/... 原始分层文件
assets/runtime/planets/... WebP/PNG 图层
assets/runtime/units/... 精灵表和帧定义
assets/runtime/ui/... 图标与 HUD 组件
assets/runtime/fx/... 粒子和扫描特效
不承诺一张概念海报自动能转换为全部动画精灵；需要重绘/重建并复核。

# 设计复核与实施验收清单
## 原始设计资产
- [ ] design/reference/v0.1/ 中 16 张编号 PNG + 4 张参考图/动画均可打开，尺寸/数量/校验和通过。
- [ ] 设计来源、用途和“非最终可生产资源”提示清楚；不把预览图误作透明精灵。
- [ ] 保留原始 8 秒动画参考供动作对比。

## 视觉体验
- [ ] 游戏主界面像素密度高且和批准的基地页一致，不出现粗糙低清方块。
- [ ] 微缩球体能明确区分球面/球背，实际预览不是平面浮岛。
- [ ] 机器人、建筑、生物、飞船的比例和颜色统一。
- [ ] 遮挡对：球后飞船不可穿帮；机器人与前景建筑不交叉。
- [ ] 360×800 / 390×844 竖屏可读；按钮可触控；没有超出安全区。
- [ ] 全屏动画不过分闪烁、UI 不掩盖球体核心动作。

## 玩法逻辑
- [ ] 星图初始不显示未发现星球数量、名称、位置、剪影或问号固定节点。
- [ ] 雷达可以自动探索、产生异常、完成定位，再揭晓独立星球。
- [ ] 第一次星球发现演出结束后写入存档，返回无需重复看揭晓。
- [ ] 机器人自动探索/拾取/回船，进度能推动真实发现。
- [ ] 普通与里程碑发现有区分；稀有发现有额外反馈。
- [ ] 图鉴和基地同步显示新发现；奇物互动不会产生重复奖励漏洞。
- [ ] 飞船、雷达、回收等升级真实改变对应数值。
- [ ] 离线结算可验证，重复进入不双倍领取；存档刷新后保持。
- [ ] 当前无真实广告 SDK、无付费、无复杂战斗、无远程敏感密钥。

## 工程质量
- [ ] 安装、构建、测试命令全部可复现，CI 通过。
- [ ] 无控制台错误、无丢失素材、无大体积参考图意外打包首屏。
- [ ] 移动端至少 30 FPS 的目标经真实设备/可复现测量；未测不得宣称通过。
- [ ] 提供运行截图、动画录屏、自动化测试及人工待验清单。
- [ ] 分支提交和 Draft PR，不擅自合并/生产部署。

# 第一阶段：首星质量基准验收记录

2026-11-02。分支 `codex/v0.1-vertical-slice`，[Draft PR #2](https://github.com/sy0310/loststar-game/pull/2)。本轮仅制作退货箱星 / 退件平原；后续星球完整远征冻结。实现和证据齐备后提交用户复审，不自行认定主观视觉标准已获通过。

## A 远征与连续动画

- [x] 保留完整闭合纸箱球体，新增独立分拣机、管线灯、纸屑与居民，球体/建筑/角色/飞船/特效分别渲染。
- [x] 机器人改为 4×2 八姿势图集，扩大主角和拆封鼠，扫描、拾取、携箱、递交可辨；本体不是整图晃动。
- [x] 去程绕仓库外侧与后方，回程走前庭；路径采样不进入地基，动作边界位置连续，接触点排序用于遮挡。
- [x] 飞船 14 秒连续绕轨，朝向取切线、尺度随深度变化；背轨被球体覆盖、前轨正确出现；无方向硬翻。
- [x] 约 42 秒真实时间连续录屏，包含三轮轨道、机器人循环和收据/拆封鼠两次真实发现；另有 12 秒同源节选。
- [x] 球背、球前、仓库后、扫描、卸货关键帧及连续联系表齐备，不能只靠静态图判断自然度。
- [ ] 用户复审角色比例、图集细微姿态与递交接触感、飞船单视角精灵转向和整体像素完成度。

## B 统一游戏 UI

- [x] 远征、雷达、图鉴、基地、工坊、奇物详情、离线归航使用统一邮政科幻面板、角饰、纸签、像素插画与暖金/青色反馈。
- [x] 图鉴为分类藏品卡，详情有像素立绘、田野笔记、入档信息和独特互动；工坊四设备有独立像素图、等级槽、当前/下级效果与费用。
- [x] 基地有六件独立展柜、机器人活动、灯光与星光循环、已发现居民反馈。
- [x] main 独立滚动，导航位于内容区外，不盖住长页操作；主要按钮与展柜触控区域至少 44px。
- [x] 精确 390×844 五页 PNG、2×版本与 360×800/桌面/WebKit 浏览器截图齐备。
- [ ] 中文最小辅助文字与不同手机亮度/字号设置需真机复审；主要描述与动作状态已提高字号。

## C 首星内容与发现体验

- [x] 完整小生态：6 奇物 / 3 生物 / 3 事件，具有独立像素图、描述、田野关系与互动；新增项详见 [本轮内容表](11_FIRST_PLANET_POLISH.md)。
- [x] 基础节奏从首个 12 秒发现逐步推进至约 12.4 分钟末条档案；设备升级缩短时间，不在约 100 秒耗尽首星内容。
- [x] 奇物、居民、事件三类非阻塞演出，含像素特效、独特短句、档案入口与音效接口；不另加奖励、不抢导航焦点、不停探索。
- [x] 刷新不重播已消费演出；离开远征积累发现只呈现最新一份；离线批量发现由归航清单承接。
- [x] 首星档案有温暖的结尾与继续日常巡回，不依靠未开放的第二星球作为短期引导。
- [x] 雷达真实监听→本地异常→核对→现场记录；升级真实改变勘测效率，完成勘测产出补给；按钮不会重复发奖。
- [x] 未发现世界不暴露数量、名称、方位、轮廓、固定问号、图片或可访问性文本。旧存档历史坐标保留，但当前不提供不可玩入口。
- [ ] 最终经济与长期留存节奏仍需要用户试玩反馈；目前是明确可调的首星版本。

## D 存档、基地、工坊与离线闭环

- [x] 自动探索→图鉴→详情互动→基地六件展柜与居民反馈→四种设备升级→继续首星勘测完整可用。
- [x] 雷达/扫描/回收/货舱分别改变速度/周期/产量/离线上限，升级前后真实值和成功反馈一致。
- [x] v1→v2 迁移保留资金、收藏、升级、历史坐标和待领取包裹；不清空用户进度。
- [x] 离线上限、负时间、损坏存档、反复恢复、重复领取、旧标签页再次提交均有自动覆盖。
- [x] 存储读写异常不重复执行消费，不因写满丢弃已读取存档；失败会提示只能保留本次内存进度。
- [x] 不接广告/付费/联机/复杂战斗/开放世界；无远程密钥。音效仅事件接口，尚无音轨。

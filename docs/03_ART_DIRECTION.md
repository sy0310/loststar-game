# 美术制作标准：精细像素 + 2.5D 微缩球体
## 核心美术原则
- 目标是“精致、有立体光影层次、有像素质感的微缩星球”，不要廉价低分辨率纯块状 UI。
- 保持所有星球、角色、道具、UI 的像素颗粒与边缘锐利程度一致；不得混入写实光滑的 3D 角色。
- 首颗星球：暖橘包裹荒原 + 紫蓝深空；青蓝扫描特效；暖金主操作；紫/粉神秘异常。
- 科幻与幽默混合：从纸箱、退货标签、传送带、收件仓等视觉母题延伸。

## 球体表现技术可选
A. 首选：预渲染高质量 2.5D 球体/少角度循环帧，叠加独立机器人、建筑、生物、飞船、UI。
B. 若轻量 3D 真正匹配概念图且性能稳定，可采用低面数球体 + 像素贴图 + 独立层，注意避免地物贴图被拉伸。
无论 A/B 均需：完整闭合轮廓、明确球面明暗、球背与球前遮挡、镜头稳定、地貌布置逻辑自然；不可只是圆形浮岛大幅摆动。

## 贴图与图层（建议）
space_bg; orbit_back; planet_back; planet_surface; decor_back; unit_ground_shadows; robot; creature; pickup_fx; decor_front; orbit_front; ship; vfx; hud.
每层可进一步分前后；机器人在建筑后走时切换遮挡，船进入背轨后消失于球背。
重要：UI 与球体不要相互遮挡；可主动缩小球体或减少建筑高度，而不是强行叠加按钮。

## 素材生产与验收
- 设计图为 AI 辅助概念稿，只用于风格、布局与故事板参考；禁止直接整张拿作可交互场景或直接剪出污染背景的角色当精灵。
- 将每个实体重新绘成透明 PNG/WEBP 或合理 3D 模型；保留源文件（如 Aseprite / Krita 分层文件或 Blender 文件），同时导出运行时资源。
- 制作首颗星球球体＋可独立渲染的建筑、箱子、植被、生物、机器人、飞船、扫描与标记特效。
- 用实际 360×800/390×844 设备尺寸对照，不只看 2K 设计海报；字号、点击面积和色彩对比要可读。
- 使用像素友好的最近邻或受控缩放；不要用连续缩放模糊笔触。
- 大图片仅用于文档参考，不随 H5 首屏打包；生产使用裁切、图集、渐进加载与合理分辨率。
- 旧的低清概念草图只供反例参考，不得作为最终画质标准。
- 六颗星球要先设计主题剪影和关键生态差异，避免全部呈现同一种“橙色星球换皮”。

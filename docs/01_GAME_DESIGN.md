# 游戏设计总纲 V0.1
## 类型与体验
- 竖屏、可低频操作的放置探索，目标平台 H5（优先手机浏览器）。
- 玩家是宇宙失物管理员，操作旧飞船“失物号 LR-01”，机器人“咔哒-07”自动勘察怪诞星球。
- 文案基调：温柔荒诞、意料之外、有趣而不靠恐怖或大量对话。
- 内容扩张：一个星球由星球主题＋环境异常规则＋若干地区＋生物＋奇物＋事件构成；区域可持续增加。

## 核心循环
1. 星图仅显示已发现星球与当前雷达实际感知的临时异常信号。
2. 雷达自动扫描；玩家可选择自愿的主动强化扫描。新信号经历“模糊→锁定→揭晓”。
3. 玩家选择已发现星球的已解锁区域，开始远征。
4. 飞船着陆/绕轨，机器人自动行走、扫描、拾取、回船卸货；星球和居民在持续运转。
5. 回收普通资源、奇物、生物图鉴及事件线索；重要发现短演出；重复物品可以回收但不是无意义的卡片刷屏。
6. 基地展柜展示重要发现；少量奇物可“试一试”触发幽默说明或隐藏互动。
7. 升级雷达、扫描仪、回收装置、货舱等；解锁后续区域与继续扫描星域。

## 首版阶段
- 美术/技术验证阶段：只做退货箱星“退件平原”，一个完全可看可操作的场景；至少机器人、飞船、1 个生物和 3 个奇物的表现成立。
- 可玩切片阶段：可进行自动探索、扫描发现、图鉴、基地展柜、飞船升级、保存恢复和离线结算。
- 内容扩张阶段：六颗主题星球配置接入；不得以单纯换色冒充不同生态。
- 绝不首版实现：实时战斗、开放世界自由走动、复杂寻路、多人联机、重型生产链、强制广告。

## 奖励设计
- 常规发现：稳定资源、少量图鉴进度。
- 里程碑发现：达到阶段保证出现新条目，避免一直挂机无新发现。
- 异常发现：随机/条件触发的稀有事件，保持惊喜，不得只用极小概率吊玩家胃口。
- 重要奇物：有名字、图标、独特短描述及基地展出；尽可能留下世界变化或互动，而非纯数字。

## 保存/离线原则
- 本地存档与版本迁移；离线收益通过上次有效时间戳结算，防重复领取。
- 初期设置离线收益上限和异常时间保护，具体数字通过数值验证冻结。
- 数据配置与 UI 逻辑分离；玩家不知道未发现星球的内部列表。

# 《失物星球》V0.3 · 球面夜间异常处置与持续成长（设计定稿候选）

> 状态：**用户已确认本方向并授权制作 D1；两份动态样板仍待用户审核，尚非正式替换版**。2026-11-03 用户要求生图交由子智能体、主智能体独立审查风格和项目约束。D1 复用 PR #2 现有球体和收藏室，仅限内部只读审核；仍为 Draft，不合并、不正式发布、不制作第二颗星球。

## 0. 一句话定位
精细高像素密度的 2.5D 微缩球体放置探索：**白天发现宇宙失物，夜晚由机器人、飞船和收件站处理异常，清晨修复与研究，从而发现更多未知。** 不制作传统塔防、密集刷怪、职业战斗、联机或多个资源币种。

已确认：
- 奇物本体留在收藏室，负责观察、互动、收藏与开启研究线索，**不是直接装备成武器**。
- 日夜变化和夜间异常发生在**远征页面同一颗完整球体**上，无独立玩家夜守入口。
- 夜晚允许真实、小幅设施损伤；零件可用于按实际损伤维修，维修成本可预测且安全。
- 资源三大去向：有条件的维修、永久工程建设、可选择且有实际效果的重复定向勘探/科研。
- 雷达始终未知优先，未定位的星球数量、位置、轮廓、名字不得预先暴露。第二星不具备完整可玩区域前不得提前解锁。
- 旧存档的余额、收藏、工坊等级、科研进度、图鉴和已获得权益必须保留；原奇物守护等级可等值映射成新设施等级或提供合理等值补偿。

## 1. 视觉总规范
- 使用 V0.2.3 已获阶段性认可的纸箱球体、收件站、机器人与飞船作为场景基础。**主视觉必须是一颗完整、可见闭合轮廓的微缩小星球**，不是被地平线裁掉的半球、平面浮岛或大型俯视战场。
- 竖屏 390×844 为主设计画布，兼容 360×800 与安全区。标题与状态栏压缩，球体视觉优先；画面内最多 2～3 只异常生物，主角与异常都可辨认。
- 高密度像素画风、统一像素密度；橙黄纸箱地貌、紫蓝夜色、暖金仓库灯光、青绿探测信号。夜间不能一味降低整体亮度以致无法判断行动。
- 球面前后关系、建筑与机器人的遮挡、飞船探照灯的事件追踪、设施报警和闸门动作应基于真实层级和接触点；禁止只在整个球体上添加变暗滤镜。
- 画面生成稿只作为**构图、氛围、层次与动效设计参考**；所有中文 UI 文案、价格、时间及星球轮廓以本文件和后续经过用户审核的真机样板为准。AI 概念拼版不是可直接生产的 sprite 资源。

## 2. 远征主屏结构（390×844）
- 顶部：LOGO/零件余额/设置与小号昼夜倒计时；最多一行重要状态（基地完整度0–100、当夜阶段）。
- 中部：完整星球为视觉核心，收件站与两处设备固定在球面上；机器人沿可见前表面行动，飞船围绕轨道并让搜索光准确跟随事件。
- 底部：一条“正在处理什么”的简短反馈，以及三个紧凑入口：**安保｜科研｜维修**。全部使用同样的底部抽屉，而不是三张常驻大卡或另一个 H5 页面。
- 底部导航继续保留远征／星图／图鉴／基地；打开奖励或面板不能遮挡夜间事件的关键动作。允许关闭抽屉后观看星球完整演出。
- 昼夜进程由统一时间与存档驱动，切页、离线/锁屏返回仍持续计时，不要求实时点击。

## 3. 昼夜循环与30秒演出样板
测试节奏先沿用 **白天240秒（最后12秒黄昏）＋夜晚60秒**；清晨最初8秒轻量反馈。时间为可调参数，不当成最终商业平衡。

- 白天：咔哒按既有路径扫描、拾取、归航，仓库日常收件；玩家选择科研与建设。
- 黄昏：纸箱地貌过渡到紫蓝阴影，警戒灯/仓库窗户陆续亮起，机器人回到收件站，飞船切换巡查路线。
- 夜晚：异常出现→识别→跨区域追踪→核验→设施响应/收容→回到基地；实际损伤按夜间过程结算。
- 清晨：画面自然恢复、单条简短值班报告显示成功处理、受损、已自动修复、待维修和新线索，不弹连续大窗。

**30秒先行样板故事板**（展示一种完整事件，不要求一开始做完60秒全部节奏）：
| 时间 | 镜头内动作 | 主反馈 |
|---|---|---|
| 0–5s | 异常在箱堆或管道处出现，雷达/警戒灯亮 | “发现异常” |
| 5–10s | 飞船探照光转向；咔哒沿球面奔赴事件点 | “正在追踪” |
| 10–16s | 咔哒扫描与核验类型，发出识别标记 | “已识别：异常类型” |
| 16–23s | 自动隔离门或警戒设备启动，收容/安全驱离 | “处理中” |
| 23–27s | 设施响应完成、追踪解除；如果有漏网触发小幅损伤 | “已处置” |
| 27–30s | 咔哒返回，飞船回到轨道巡查，日志写入 | “巡守完成” |

## 4. 三种异常生物（首版内容）
| 生物 | 异常性质 | 轮廓与运动 | 机器人/设施处置 | 发现后的内容 |
|---|---|---|---|---|
| **漂行纸影** | 错投、迷路 | 半透明纸片状漂浮、折叠、绕箱堆滑行 | 搜索光显形→咔哒核验→引回邮路 | 观察图鉴与来历短句 |
| **弹跳空箱** | 通道阻塞 | 清晰纸箱外壳，定间隔弹跳、落地震动 | 咔哒追逐→隔离闸门关合→收容到回收区 | 生态档案与箱体线索 |
| **环灯纸蛾** | 灯光干扰 | 温暖环形发光翅膀，沿灯具螺旋盘旋 | 设施调整灯光→飞船搜照→温和驱离 | 夜间观察条目 |

美术要求：每种独立精灵轮廓、2～4帧待机/移动、1组被核验与收容动画。同屏最多2～3只，低亮度下也要有可读边缘。不把生物设计成需要击杀的敌人。

## 5. 安保与科研的底部抽屉
### 安保（两个实际设备位）
- **A：警戒探照灯**。发现异常并照出轮廓，等级影响照射范围/发现时间。
- **B：自动隔离门／捕捉网**。阻隔或安全收容异常，等级影响关闭速度/处理时间。
- 每卡显示清晰像素设备、等级、当前作用、启用状态、下一次升级费用；选中时主场景高亮对应设备并进行少量真实动作预览。
- 咔哒负责追踪与核验，失物号负责轨道搜索与位置支援，两个设施提供明确的能力，不是换皮炮塔。
- 白天可以安排装置，夜间自动执行；夜间配置使用开夜时快照，避免半夜改配置导致结算不一致。

### 科研（任务票）
- 一张票仅有 **目标／耗时／实际效果／零件成本／开始或取消／当前进度**。
- 例：异常路径分析→在已实现的夜间事件中提高识别效率；材质回收研究→改善基地设备维修效率；定向地表勘探→引导现有可用异常事件的发现。**不得研究出尚未制作完成的第二星球或虚构不存在的掉落。**
- 首版同时进行1项，按可用资源和完成状态消费，实验产出必须在已实现机制中可验证；离线结算有上限，取消退款规则需要明确。
- “科研是有结果的工程任务”，不要写无止境高价进度条或只有文案的假研究。

## 7. 零件与损伤维修经济
唯一货币继续是零件；基础收藏、奇物“试一试”、普通远征与基础安保始终免费。
- 基地完整度0～100，夜晚异常实际到达/阻碍收件站时产生小幅损伤；结果由**实际同源事件时间轴**决定，与机器人、飞船及设施等级相关，不能按“配了几个槽”虚构战果。
- 清晨**只有损伤才收费**，支持自动维修默认开、手动维修、关闭自动维修。初步示例每点损伤3零件；不视为定稿。
- 余额不足允许按实际可支付数量部分维修，不得负余额/产生债务/永久中断游戏；未修损伤最多小幅降低探索效率（初版建议累计上限20%，待模拟）。
- 离线维修的自动预算上限为实际可用零件与有效离线收入的安全额度，初步建议不超过**该段有效离线收入的30%**，不在长时间离线后制造巨额应付维修账单。
- 持续投入的另两类用途：永久基础设施/机器人/飞船工程＋可重复但确有实际收益的定向调查/科研任务。不能靠任意提价、无限级别或清空已有余额解决通胀。
- 原胶带/签收铃守护装置升级的玩家权益，迁移到新安保设备或等值补偿，先出一份迁移表；旧余额（含约27,000零件的老玩家）全部保留。
- 样本对照：起始120 / 5,000 / 27,049 / 50,000零件，0/15/30/60/120分钟与8/24小时有效离线；分别看不消费、偏探索、偏防护三策略的产出、支出、受损、修复、最终资源、可执行科研次数与收益。只用真实已实现效果来评估。

## 9. 验收与风险约束
- 视觉：完整闭合球体、夜间动作可辨、角色不穿箱/不漂浮、建筑和飞船遮挡自然，三生物能一眼区别；收据柜结构升级至少两处肉眼可见差异。
- 交互：不强制守夜，不在主屏塞满卡片，抽屉可关闭，声效尊重静音和减少动态偏好。
- 数据：旧存档不丢资源/奇物/升级/图鉴；离线与在线同源；维修与科研费用幂等；低余额不锁死；未知星球不泄露。
- 环境：360×800、390×844、WebKit/Chromium 仅是模拟；真实 TapTap WebView 必须复测画质、发热、网络恢复、切后台与交互可达性。
- 协作：仍使用 GitHub Draft PR #2，不自动合并、不正式发布、不增加第二星；新素材需附原始源、运行时导出、授权来源和用户审核说明。

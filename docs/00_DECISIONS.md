# 产品与美术已确认决策（2026-11-02）
## 已确认
1. 游戏名暂定《失物星球》（Lost Planet）；第二款轻量 H5 像素放置探索游戏。
2. 核心钩子原话：“你的飞船会自动探索怪诞星球，每次回来都带回一些完全搞不懂用途的宇宙奇物。”
3. 乐趣优先级：未知探索与惊喜 > 看见角色自主活动 > 图鉴收集/基地变化 > 数值增长。
4. 怪诞猎奇、幽默和少量悬疑；有辨识度的原创生物、物品、环境规则。
5. 首批六星是内部内容矩阵，不是玩家初始可见关卡表。星球与区域均可扩展。
6. 视觉：高像素密度、完整度高、统一材质与阴影的精致像素风；可以 2.5D/伪3D，必要时使用低复杂度 3D 球体＋像素贴图。
7. 远征：屏幕中央完整微缩星球；咔哒-07 沿球面可见区域行走/扫描/拾取，失物号飞船沿前后分层的轨道巡航；星球上的生物作低成本循环动作。
8. 远征动画初版运动方向已认可；仍有机器人与环境、飞船与地貌遮挡不自然的问题，必须优化。
9. 基地首页设计方向认可。
10. 星图：未发现的星球不能出现数量/位置/剪影/问号占位；通过雷达扫描→异常信号→定位→揭晓，才被记录在永久星图中。
11. 当前为设计交付与 Codex 实施准备；视觉参考图不等同可直接上线的素材。

## 尚待实现/复审
- 2.5D 分层与真正 3D 球体孰优：以真实运动、空间遮挡、移动端性能、视觉一致性共同决定。
- 球面上多角色比例、像素密度、建筑深度与中文 UI 的阅读性。
- 雷达扫描成本、产出率、离线时长与升级数值尚未冻结。
- 首发怪物/奇物逐个原创定稿，概念图中文字需重校。
- 正式素材独立透明层、不同朝向、动画精灵帧需二次制作。

## 绝对禁止的误解
- “轻量” ≠ 低清、廉价或简单几何色块。
- “像无人深空一样”指未知探索感，不是实现 3D 开放世界、生存和大地图。
- 六颗星球的策划图 ≠ 玩家一开始看到全部六颗星球。
- AI 概念拼版 ≠ 可以直接拿来当游戏点击界面或动画精灵。

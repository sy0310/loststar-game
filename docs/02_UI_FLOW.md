# UI 页面与交互说明
## 统一导航
- 底部四区：远征｜星图｜图鉴｜基地。导航仅切换视图，不中断自动探索模拟（除明确的暂停）。
- 主操作高亮暖金，信息高亮青蓝，神秘/稀有提示使用紫色；背景较深但文字必须清晰。
- 手机竖屏安全区域适配；不可出现底部导航挡住操作、顶部资源条遮挡星球的情况。

## 01 基地主页面（方向已认可）
- 主视觉：空间基地、入港飞船、咔哒-07、收藏柜与奇特生态罐。
- 主 CTA：开始/继续远征；次入口：今日异常、收藏展示、设备升级、研究。
- 已发现物品进入基地展柜；重要物件应可被点击查看详情。
- 不必每个装饰都有交互；避免主界面按钮密度过高。

## 02 球体远征主页面（方向认可，遮挡待优化）
- 中央球形退货箱星为绝对焦点；体积感明确、不是平面圆形浮岛。
- 主角色活动区在球体正面可见部分；需要检测与建筑、边缘、轨道前后关系。
- 星球上方/侧面显示简明进度；底部仅保留当前探索状态、最近发现及两三项升级。
- 飞船在椭圆轨道上运行，经过球背时被球体挡住，经过球前时覆盖球体；禁止永久覆盖文字。
- 机器人移动/扫描/拾取/回收，稀有发现有短暂停顿和亮相；普通发现轻提示。

## 03 未知星域雷达（设计强约束）
- 初始大面积暗色星云与真实雷达扫描区；不要六个问号、六个锁定槽位或已知星球剪影。
- 默认允许已发现的退货箱星（新手剧情已获得）显示在记录星图中；未发现区域无预设目标数。
- 雷达自动扫；发现异常才显示模糊信号区域，定位完成才揭晓星球名称/外观/新航路。
- 内部数据里可以定义六星，但玩家可见 UI 与文字不可泄漏总数或名单。
- 探索结束后，已发现星球永久保留，星图逐渐丰富。

## 04 星球揭晓
- 雷达扫过→异常波纹→坐标锁定→剪影逐渐展开→完整立体像素小星球亮相→可“前往探索”。
- 揭晓是可跳过的短演出；不应每次回到已发现星球重新播。
- 当未捕获异常时，只显示继续探测，不虚构发现。

## 05 图鉴
- 四类：奇物／生物／事件／已发现星球；筛选与详细卡片。
- 未发现条目不可提前显示真实名字或像素图；可以仅展示整体发现进度，注意不要从数量间接泄露未知星球数。
- 详情卡片：高精细像素立绘、发现时间/区域、简短怪诞描述、基地互动入口（若有）。

## 06 收藏与奇物互动
- 角色回归后可视化展示“带回来的东西”；简单点触触发幽默事件。
- “会道歉的胶带”“未购买的退货收据”等有可读的奇物信息，互动要轻。

## 07 装备升级
- 雷达（探测）、扫描（效率）、回收装置（收集）、货舱（收益/持续时长）四个方向。
- 只展示真实可计算的效果、升级费用和级别；不要使用概念图中的虚拟示例数值作为最终平衡。

## 08 离线归航 / 09 异常事件
- 离线结算展示探索时长、物品、资源和首次发现；重复进入时不重复领取。
- 异常事件短文字＋一张小像素插画/局部特效；重要剧情线索记录到图鉴。
- 允许暂停阅读，不影响后台计时或导致资源倍增。

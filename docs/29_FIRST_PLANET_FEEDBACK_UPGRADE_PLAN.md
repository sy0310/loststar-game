# 首星实机反馈升级计划

2026年11月4日。依据TapTap432215、运行源码59670a6、资料提交a8779ae和本轮手机反馈制定。用户认可简洁方向，要求增强点击反馈、改善收藏动画、建立奇物本体成长、融入地名冷笑话，并让区域挑战和零件消费形成持续目标。本次交付包含现状审计、预算投影和实施合同。新增动效、能力与区域属于待实施样板。

## 体验目标与范围

玩家继续通过探索、收藏、基地三个入口游玩退货箱星。点下能看见反馈，升级能改变物件的动作和实际能力，能力与工程帮助机器人深入同一星球的新区域。自动探索持续提供基础进展。

第2点按用户补充理解为星球内容的矩阵化扩展，以及升级后推进更深挑战的成长感。首轮落实为退货箱星内部的区域和勘探层级。星际发现仍由真实扫描与定位驱动，已发现航路永久保存。区域内部的数据结构支持后续内容增量配置。

## A　点击与收获反馈

一次短触沿以下顺序呈现。

1. 下一可绘帧在实际球面触点出现小型像素接触纹，跟随球面光照和遮挡。
2. 存档事务返回接受结果后，一段短扫描轨迹传到咔哒当前作业点，眼灯与扫描器做收到动作。进度条显示已排入工作。
3. 助力被实际消耗时，扫描扇区、纸屑或拾取动作加强，进度连续推进。最多5～6条短特效各自收尾。
4. 完成一轮后，实际拾取物进入货箱，真实新增零件从卸货点飞向钱包，数值与账本一致。
5. 队列满、冷却、保存失败和夜间检查采用各自的短反馈，当前动作和可执行状态清楚可见。

候选验收采用触点反馈P95≤80ms，成功回执后80ms内出现助力确认。两种屏宽下连续5次输入逐次可见。有效点击600ms、滚动12秒5次、队列3000ms沿用已测候选值，收益调整在新区域经济模型中单独测量。输入序号、长按、拖动、双指、兼容click及角色点选沿用原防重规则。夜间点击聚焦当前自动处置。

## B　收藏室与近景流畅度

统一实时绘制时间，根节点位移、取放轨迹、玻璃开合和本体展开采用连续时间。静态升级前后对照使用明确的冻结时刻。低帧腿部精灵与连续位置分别调度。

- 可见活动场景先保证稳定30Hz，性能足够时提升到60Hz。使用累计时间调度，修正50ms阈值在60Hz屏幕上形成的50／66.7ms交替。
- 缓存稳定的泥层、补痕和接触锚点，单件近景绘制所需展位图层，离屏生态区暂停绘制。
- 恢复每件的局部关节。胶带用卷轴和尾带，套娃用盒盖和内盒，邮戳用手柄和印面，包裹用缝口和内光，铃用罩体和铃舌。
- 咔哒采用到位、转身、接触、抓稳、提起、放稳、松手的连贯阶段，弯角减速，工具与物件保持同一接触点。
- 减少动态设置降低装饰运动与粒子，必要作业保留清楚的动作和结果。后台恢复后按统一世界时间衔接当前阶段。

验收分别记录整页rAF、对象真实绘制间隔与状态提交耗时。候选真机目标为绘制中位≤33.4ms、P95≤50ms，10秒内本实现产生的连续100ms定格为0。60Hz桌面rAF P95≤20ms。基地35秒整理、六件近景、反复开关详情和锁屏返回均需连续录像。

每段纸层或机关显示实际剩余作业量，咔哒清障和处理异常时有受力、碎屑与收势反馈。区域阻力逐渐提高，装备和能力升级让处理过程明显变快。难度由所需基础工作、干扰条件、核验步骤与既有安保压力共同决定。设备升级缩短实际作业，奇物能力改变特定障碍的处理方式。1.8／2.4／3.2倍工作阻力仅为预算讨论参数，正式值在真实节点模型中测量。

## F　零件入口与持续用途

探索的升级入口同时承接设备和当前区域工程。零件钱包可点开三项当前推荐目标，给出价格、实际改善和场景预览。基本设备全满时，主推荐转为已发现区域的工程或本体研究。基地建设台以视觉热点接入，收藏详情提供研究与展柜两个清楚入口。

支出面向四类可见成果。

- 整理与维修。物理清洁、补纸、设施完整度和维修价格均有实际结果。
- 区域与基地工程。施工完成出现可工作的局部设施、路线或生态变化。
- 奇物本体研究。实际能力、生长动作和已取得记录一起变化。
- 定向作业。投入补给后执行指定节点，带回实际样本、研究进度或可比较的观察片段。

当前调查180／240／300零件，在满级白天样本中只多入账23／46／46零件。新的定向作业需要可执行目标、可预览成果、有效作业时长与取消退款规则。重复核对同一已完成记录采用免费复核。可推荐的付费任务与尚有价值的研究或区域目标关联。高级作业的收益、损伤和投入在实际模型中联合验证。[当前调查对照](../artifacts/fusion-feedback/research-return.csv)

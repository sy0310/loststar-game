## P1：从固定统计改成一份确定性事件时间轴

新增 `src/prototype/night-model.ts`。每个标准60秒夜晚使用100ms固定逻辑步长，只包含三位同种访客。配置确定后，纯模型生成出生、区域减速、铃声停顿、提前核验或抵站、安全送回事件及对应姿态。实时 `guardView()` 从这份时间轴取样，`advanceGuard()` 的在线/离线晨间记录读取同一模型结果；不再使用槽数计算拦退数。

- 出生时刻4.2 / 22.2 / 40.2秒，未受影响的全程移动时间15 / 12 / 9.6秒，代表同一种纸影的三种步速，不增加怪物类型或波次。
- 胶带A/B分别影响路径进度0.34–0.58 / 0.64–0.88；移动系数从0.56随槽等级每级降低0.06，最高0.38，即区域减速44%→62%。
- 铃在本槽范围内每6秒触发一次，停顿1.1秒，每级+0.2秒，最高1.7秒。能力数值由 `src/game/guard-tuning.ts` 同时提供给模型、工坊和守护槽说明，避免文案与实际效果漂移。
- 访客进入进度0.32之后，机器人/飞船持续核对封条。抵站前累计完成10.5秒核对才算“提前拦退”；到站优先于同一逻辑步里的核验完成。减速与停顿延长这个实际窗口，等级改变访客位置、有效停顿和最终是否及时核验。
- 未及提前拦退的访客到站后由基础自动守护安全送回。没有收藏损失、余额扣减或失败复活。实验线索为1+实际提前拦退数，仅留在实验值班簿，不兑换正式零件/奇物。
- 当夜配置和强度在入夜时固定；夜间调整应用于下一夜。暂停不推进实验时间，退出页面仍按此前开启的配置自动结算；最长离线推进12小时，重复恢复不重复记账。
- V0.2旧实验总数/线索保留，旧日志明确标为旧版演示记录，不追溯冒称已经由新模型验证；新夜晚附三位访客的完整结果和新模型核验夜数。正式存档键不变，实验不写正式余额和收藏。

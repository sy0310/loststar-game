## 样板A

退货箱星保留原完整球体、飞船绕轨和三居民。单处星雾覆盖已经实现的旧分拣区，18秒自动经历未探明、扫描、分层散雾、地点露出和机器人靠近。地点名称在揭露后出现。

背雾、主体、前缘分别呼吸和卷动，局部扫描路径侵蚀遮罩，暖边和星尘保留在独立像素素材上。雾下接触暗影与紫暖反照从真实地形像素生成，随散雾解除，仓库继续遮挡前景。

轻触保留原600毫秒有界工作，12秒最多5次，队列上限3秒。触点、信号到机器人和真实工作进度分开呈现。自动观察同样能完成。揭晓后，飞船与居民继续活动。

## 样板B

同一原收据在取回土样的整理台上经历28秒演出。初态只露纸角，刮铲松土后，机械臂夹稳纸根，分段展开，碎土落回托盘。刷毛沿真实接触路径擦掉泥层，返程抬起。两处纤维背贴和正面补片分别对准、落下、压合，松动上角稳定，卷根恢复展开。

原纸、RET-031、未购买戳与签收空栏保留。清洁、补纸和试验产生物理动作与风味回应，正式证据数保持0。免费试验打印“您尚未购买任何商品”，可以重播。

玻璃后层、纸与阴影、前缘高光分别绘制。纸底、托盘与玻璃地板共用实际接地点 `(320,490)`。玻璃位置由已有320像素源图登记的地板中心 `(172.5,263.5)` 逆算，前后层投影分别核对。

## 隔离与生命周期

两个样板只使用内存状态，重播恢复演示起点。浏览器测试以正式存档哨兵监测localStorage和IndexedDB调用，原值保持完整。已有游戏、融合审阅库、余额、收藏、设备与研究权益继续由原入口承接。

暂停与后台会停住样板时间，减少动态保留必要接触过程。加载前暂停仍绘制零时静帧，暂停时试验按钮禁用，恢复后按当前状态启用。素材先失败会显示受控提示，可以切换另一个样板。共享场景补齐异步加载后的销毁检查，快速切换后保留一个有效绘制循环。

### 独占绘制采样

Apple M2 Pro、macOS arm64、390×844、DPR2，每次一个无录屏的浏览器页面，预热1秒后采样10秒。实际对象绘制间隔的中位数/P95如下，单位毫秒。

| 对象 | Chromium | WebKit |
| --- | --- | --- |
| 星雾普通 | 16.7 / 16.8 | 32 / 33 |
| 收据普通 | 16.7 / 16.7 | 17 / 17 |
| 星雾减少动态 | 33.3 / 33.4 | 33 / 34 |
| 收据减少动态 | 33.3 / 33.4 | 33 / 34 |

八组对象采样中超过100毫秒的绘制间隔均为0。星雾每组取得4次触点首次Canvas绘制样本，普通模式P95为Chromium14、WebKit13毫秒，减少动态为29.6、41毫秒。终点为CPU执行绘制调用，浏览器呈现与物理触屏延迟仍待实机验证。

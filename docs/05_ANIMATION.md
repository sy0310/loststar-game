# 远征动画、轨道与遮挡验收规范
## 8 秒参考动画的定位
上一轮 8 秒演示已获“总体可以”的反馈；存在机器人和环境遮挡、球面运动不自然问题，属于方向预览而非成品。
实际实现不应只平移/旋转整张设计图来冒充立体星球。

## 核心循环
1. 飞船：椭圆轨道巡航、大小及层级变化，经过球背时正确遮挡，球前时出现；停靠/巡航速度自然。
2. 机器人：待机→行走→发现目标→停下扫描→拾取→返回卸货。推荐基本走路 4 帧、扫描 3–4 帧、拾取 3–4 帧；以可见地表路径点驱动，首版不做真正球面全向行走。
3. 生物：1–4 帧可复用眨眼、抖动、拆箱、搬运；即使玩家不操作，星球也有细小变化。
4. 环境：旗帜摆动、雷达转向、蒸汽排出、航标灯等，选择少量画面重点处循环。
5. 发现：扫描圈→短暂光效→物品亮相；普通掉落不过度打断，稀有发现独立小弹层。
6. 球体：如自转，建议非常慢（概念 15–30 秒每圈，仅参考），不能让建筑无故滑动、贴图撕裂或机器人物理位置不符。

## 画面遮挡与空间一致性
- 每个运动对象有显式 depth/layer 与可见区判断；前方建筑可挡住机器人，机器人不能透过实体箱子。
- 对球体背面的轨道飞船必须遮挡；背面不可出现悬空机器人。
- 生物不能与建筑/奇物在同层相互穿模；地面接触点和投影不能漂浮。
- 遇到遮挡严重的构图，优先调整移动路线、建筑位置和球体镜头角度。

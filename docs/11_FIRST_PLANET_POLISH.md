# 第一阶段：退货箱星 / 退件平原成熟化

2026-11-02。本轮只打磨一个可玩星球；阶段二冻结，必须先经过用户审核。以下为实现与验证记录，不替用户判断最终美术是否达到标准答案。

## 场景与动画

- 保留已验证的完整闭合纸箱球体；没有平移整张概念拼版冒充动画，也未引入真正 3D。
- 主角使用新制 4×2 图集：4 个行走姿势、扫描、拾取、抱箱、递交。显示尺寸从旧 65×79 的组合切片提升为 144 像素对齐单元，实际可见机器人约 90×125；拆封鼠从 64×69 提升为 83×89。相同手机视口中辨识度明显提高，图集内个别肢体连续性仍待视觉复审。
- 去程沿仓库外侧、后侧到扫描点；回程走前庭。曲线路径不进入仓库地基，动作边界位置连续，深度按地面接触点排序。仓库后方保留头部可见；卸货动作在门口递交，不让角色走穿墙体。
- 飞船按 14 秒轨道连续运动，朝向取轨道切线，不再在方向切换时左右硬翻；尺寸随深度平滑变化。背轨先画、球体再画、前轨最后画，背面中段完全覆盖。连续录屏完整记录三轮绕轨。
- 新增独立分拣机、指示灯、传送带小动件、附着管线灯、纸屑、居民日常动作。箱寄居蟹、标签鸟随真实发现进入地表；场景不会预先显示它们的图鉴名称。

## 首星小生态

| 类别 | 完整首星条目 | 本轮新增 |
| --- | --- | --- |
| 奇物（6） | 未购买的退货收据、自动道歉的胶带、无限套娃包裹、收件人：宇宙、只会盖昨天的邮戳、无人签收铃 | 后三件 |
| 生物（3） | 拆封鼠、箱寄居蟹、标签鸟 | 后两种 |
| 事件（3） | 没有员工的夜班、来自星球的退货申请、留给管理员的空白地址 | 夜班、空白地址 |

新增独立像素素材、专属描述、田野笔记和“试一试”。生态关系是拆封鼠拆箱、箱寄居蟹复用纸箱、标签鸟回收邮签；无人夜班逐步解释平原的退件习惯，空白地址为首轮探索收尾。

基础周期 12 秒：首张收据约 12 秒，小鼠约 36 秒，夜班约 3 分钟，末条记录约 12.4 分钟；扫描升级会缩短时间。不是原来约 100 秒就耗尽全部内容。当前仍是可调试玩节奏，不宣称最终平衡。

## 发现演出与音效接口

三种非打断式演出：奇物的暖金展开、居民的青绿相遇、事件的紫粉现场记录。至少两种在实际连续录屏里触发：12 秒收据、36 秒拆封鼠。演出配独立图像、短句、像素粒子、地表局部强调和档案入口，自动收起，也可手动收起；不拦截导航、不暂停探索、不另加奖励。

演出消费写入存档，刷新不重播。离开远征积累多份发现时，只呈现最新一份并提示其余已入档；离线批量发现由归航清单承接，不连续弹十几次。

`src/ui/discovery.ts` 派发 `loststar:sound-cue`，cue 包括 `discovery-parcel/resident/glitch`、`upgrade`、`return`、`interaction`。目前没有接音频或 SDK；未来音效消费者只处理声音，不拥有奖励权限。

## UI 与完整闭环

- 共用紫蓝邮政科幻底色、双层金属边框、角饰、纸签标签、暖金操作与青色设备反馈，覆盖远征、雷达、图鉴、基地、工坊、详情、离线归航。
- 图鉴改为有编号、分类、像素立绘与田野笔记的藏品卡；只输出已收集的名字和图像。首星档案进度明确，不显示未知世界总数。
- 基地六件奇物都有独立展柜位置、轻微陈列动效与详情入口；机器人在基地走动，灯光和星光有小循环，已发现居民在邻居记录中出现。
- 工坊四设备使用独立像素图与等级槽，展示当前值/下一级/费用，成功后给出真实新值；不足费用和满级禁用。
- 归航显示有效时长、实际零件、首次发现图像清单及货舱上限。保留离线限额、负时间保护、防双领和多标签页同步。
- 内容在独立 main 滚动区，导航位于区外；长页不会被固定导航盖住。五页截图为精确 390×844，另有 2×版本。

## 冻结扩张与保存兼容

雷达现在聆听退件平原，真实扫描经历“监听→本地异常→核对→现场归档”，记录四类本地回波；继续扫描提供勘测补给。雷达升级真实提高现场勘测速度。没有捕获的信号不显示位置，没有核实的现场不显示身份。

不再两分钟后把玩家引到不能远征的第二世界。后续数据接口保留，当前 UI 只提供已可玩的已知航路。旧 v1 存档迁移至 v2 时，资金、收藏、升级和历史坐标保留；未开放的历史坐标保存在数据里，不弹不可玩的入口，也不删除用户进度。

存储读写分离，写满时不丢弃已读取的存档，消费仅执行一次；存储不可用会明确提示本次只能保留内存进度。旧版本未见的新首星里程碑可按已有航程补录，不清空旧收藏。

## 审核后仍可细磨的事项

1. 机器人 AI 辅助动作图集的细微姿态一致性、递交手部与仓库门口的接触感，可继续手工修帧。
2. Phase 1.5 已改为四方向精灵 + 小角度倾斜，增加同源连续放大视频；方向中间角度仍可继续补帧，最终自然度由用户复审。
3. 中文最小辅助文字、低端机画面与长时间发热需真机检查；目前只测桌面浏览器的手机尺寸与 CPU 模拟。
4. Phase 1.5 已接原创 Web Audio 短音效、静音/字号/首页设置与 15–60 分钟居民续记；玩法数值仍需试玩反馈。
5. 最终视觉完成度和本阶段是否过关由用户审核。本轮不继续制作任何后续世界，未合并、未部署。

# TapTap 实机反馈 P0 修复

依据 [最新 Review](https://github.com/sy0310/loststar-game/pull/2#pullrequestreview-5747020255)。基线为 TapTap 开发自测版本 422632（Git `fc572cc`）。本轮优先修复飞船喷口、雷达和“试一试”，再提供独立夜间实验；不改旧存档，不开放后续星球。

## 复现与诊断边界

用户在 TapTap 物理手机上报告三项体验缺陷。当前工作站没有可调试手机/ADB/iOS 调试环境，用户选择通过扫码复测，因此不得把以下桌面触控模拟写成真机通过。

- 尾焰：旧 `drawShip` 尾焰按切线单独旋转，机身按四向图集和小倾角旋转，二者没有共用喷口锚点。已从代码确认两个坐标系不一致。
- 雷达：在与旧上传 ZIP 相同的构建上，Chromium 触控模拟设置 `prefers-reduced-motion: reduce` 后，`.sweep` 的时长变为 `1e-06s`，只运行一次；这是可复现的失效路径。尚未确认用户手机是否恰好设置了该偏好，也不能据此声称已锁定 TapTap 的唯一原因。
- 互动：旧包正常 390×744 触控模拟下，点击事件确实触发、文字确实更改，不能声称复现了“事件没有触发”。360×640、150%文字时，物品动作区域处于可视区域外，而文字仍可见；旧的轻微摇动、静音默认和重复同文案缺少明确的就近反馈。具体手机差异仍需新包复测。

[旧包诊断 JSON](../artifacts/mobile-fixes/baseline.json) 与前后截图保留，明确标记浏览器模拟。

## 实施

1. **喷口注册**：按四个 256px 精灵单元分别标定鼻端、喷口与本地轴线。交叉淡入两层都以共同喷口注册，机身和尾焰同向变换。尾焰四帧、长度随轨道速度/尺度变化，最多八个历史尾迹点消散，整组和飞船共用球前/球后层级。没有增加3D模型或高数量粒子。
2. **Canvas 地表勘测**：明确可见的扇区、扫描线、扩散波、本地异常脉冲、锁定框、归档回波。避免依赖 conic-gradient、CSS动画和全局减弱动态样式；减弱动态时降低刷新率，仍保留必要状态动效。切页/后台停止重绘，回来恢复。星际频道继续待接通，不导入未知目标列表。
3. **就近互动演出**：详情改为固定头部＋独立滚动正文＋固定操作区。六件奇物均有独立 Canvas 动作：收据吐票、胶带伸展、套娃展开、邮戳落印、宇宙包裹星光、签收铃声波。三居民/三事件亦有对应反馈。文字和动画紧邻按钮，可关闭、重复播放；不修改资源、藏品、升级或离线包裹。默认静音继续生效。
4. **包体识别**：游戏版本升为0.1.1，在设置中显示版本与 Git 提交；工作区未提交构建明确标记“本地修改中”。旧 v1/v2 存档键和数据保持兼容。

## 工程验证

- `npm run check`：20/20设计原件、26项单元/运动测试、构建、54项浏览器流程通过。
- 新增两个明确标记的触控模拟项目（Chromium/WebKit，`isMobile + hasTouch`），使用 `touchscreen.tap`，校验 pointerType=touch。
- 覆盖六件奇物＋一生物、可视区域、Canvas像素变化、重复点击、不多发奖励、刷新存档、小屏150%文字、44px关闭按钮；雷达在减弱动态下仍变化、切页恢复。
- 这些测试不能代替 TapTap 真机触控、GPU、帧率和手机实际观感。新包扫码确认由用户进行。

录屏、上传回执、版本ID和手机反馈将继续追加本页。夜间守护方案见 [独立实验设计](15_NIGHT_GUARD_PROTOTYPE.md)，默认不进入主流程。

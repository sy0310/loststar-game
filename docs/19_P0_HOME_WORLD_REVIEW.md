## 基地首页就是收藏室

移除首页的静态 station 背景、小型 mini-vessel 和 CSS base-roam 机器人。首页直接挂载 `MuseumScene`，六件实际奇物贴图及玻璃背层→奇物→透明前层/高光→铭牌由同一 Canvas 渲染。进入近景收藏室时移动同一个根节点和 Canvas，返回基地再移回，既没有复制一套图片，也不重置动画。

- 六组独立容器/铭牌，收据飘纸、胶带摆尾、套娃轻开、邮戳落印、宇宙包裹轨环、签收铃声波沿用已批准的实际美术体系。宇宙包裹、邮戳与签收铃增大实际显示比例；宇宙封存舱前玻璃减弱不透明度，保留背层实体边框。
- 首页与近景使用同一资产映射、所有权、展柜等级与交互。点击实际展柜即可打开详情、反复“试一试”，不刷奖励。基础容器免费；升级外观/付款反馈仍有效。
- 机器人纯路径状态机每14秒服务一柜：行走4秒→观察→开罩→取出→检查→放回→擦拭关罩→返回。28秒两次不同目标，长期轮流访问全部六柜。按脚底深度与柜体排序，机械臂连接玻璃内的实物与手持接触点，不额外复制一件藏品；开罩时透明前层侧移。
- 使用原有空手机器人8格精灵，逐格校准脚底像素。减少动态偏好下必要作业保留10Hz，普通20Hz；不是把整个收藏室背景摇动。后台暂停绘制，恢复后根据持久世界时间定位当前作业。
- 房间、机器人、六张奇物与十二张玻璃全部 decode 完才显现。慢网有一致加载状态，失败提供重试；未发现物品仅空柜，不展示占位样品。

## 原远征自然昼夜，统一时间与存档

`SaveData.world` 在原 `loststar.save.v1` 键内作增量扩展，仍为兼容的 v2 数据。新存档默认推进4分钟白天（最后12秒黄昏）＋1分钟夜晚；晨间前8秒显示清晨。已有正式资金、收藏、图鉴、升级、航路、来信与待领取货物保留。旧 `GUARD_KEY` 实验样品/线索完全隔离，绝不导入正式藏品。

远征仍为同一 `ExpeditionScene`、同一完整球体、机器人与绕轨飞船。接入 `guardLayer`，使用按球体透明轮廓缓存的暖昏/深蓝材质色和局部仓库灯光，不突然换整张背景。入夜与清晨衔接机器人的原路径；飞船喷口、尾焰与前后遮挡修复保持。

两个守护槽在远征可展开区配置，只列真实拥有的胶带/铃。白天与黄昏可改，夜晚锁定本夜快照；工坊当夜升级也不改正在发生的结果。空槽仍由机器人/飞船基础照看，访客安全返回，不扣零件、不损失收藏。

白天探索，夜晚暂停回收、执行同源守护。胶带减速、铃声停顿、封条核对、提前核验/抵站护送和晨间三位记录全部来自既有确定性时间轴，基础双槽2位提前核验，满级3位。晨间是一条安静的可展开值班簿，守护线索自动记账、没有重复领取按钮，也不兑换正式零件。

- 主时钟按真实时间推进，切页/离线不中断；长离线批量计算，复杂度不随离线夜数增长。正式货舱收益仍有原上限。时间倒拨不倒退/重发；世界时间有1e12毫秒数值保护边界。
- 旧存档没有 world 或此字段损坏时只初始化昼夜，不清理旧资源。配置仅允许真正已发现奇物，实验页从不进入正式包导航。
- 守护槽选择在事件触发时立即捕获，防止存档锁等待期间界面刷新覆盖第二次选择；Chromium/WebKit 触控回归已覆盖此竞争。
- 正常构建仅 `index.html`＋资源，既没有独立夜守链接，也不含 night-lab.html。内部实验源和回归测试保留，便于模型对照。

## 交付入口和存档边界

- 开发入口 `npm run dev` 后访问 `/?sample=fusion`；独立构建 `npm run build:fusion`，TapTap相对路径包 `npm run package:fusion`。
- 集成包默认进入“探索／收藏／基地”，有真实收入、消费、收藏和持久进度。普通构建入口继续保留已有版本，等待本轮视觉与交互审核后再决定迁移接入。
- 新包使用独立 IndexedDB `loststar.fusion.v1/archive/current`，同源存在旧 `loststar.save.v1` 时只读导入副本。旧余额、升级、收藏、安保、展柜和原科研权益完整保留；已拥有奇物承接基础整理权益。
- TapTap不同自测版本是否共享同一来源由平台决定。若新版本的浏览器来源不同，包无法读取另一个来源的旧档；当前没有账号或云存档。27049旧档兼容已经过受控导入验证，不能把这项测试等同于平台跨来源迁移成功。
- IndexedDB事务串行完成读、推进、核价与写入，多标签同步以提交修订为准，不依赖 Web Locks。保存失败进入免费观察模式，付费指令暂停，恢复后重试；坏档保留原记录，不覆盖重建。

## 已实现的完整循环

### 探索与成长

首屏保留完整分层球体、独立机器人、前后绕轨飞船。导航收为三个入口，静止首屏正文不超过80汉字。主升级只有“机器人：探索更快”和“飞船：带回更多”；雷达、货舱放入更多设备，沿用原四种升级ID和实际计算。

有效轻点排入600ms勘探工作，至少相隔300ms，滚动12秒最多5次，队列最多3000ms，每真实秒平滑应用最多600ms额外基础工作。助力随完成工作结算零件，世界时钟、雷达和夜班不加速。余量有界持久保存，离线只补已有队列。

点机器人或飞船打开设备，点已发现居民打开相应详情，空白处无工作奖励。实际绘制的裁切、相机、朝向、透明像素和前后遮挡用于命中。长按、拖动、第二触点、滚动、取消、键盘重复和派生兼容点击均有过滤。夜间点击只聚焦同一现场，不改变防御结果。

### 六件奇物与统一收藏室

基地、收藏与近景复用同一分层展柜：原玻璃后层、物件、前层反射、台座和铭牌保持注册。机器人真实走向不同展柜，观察、整理并返回。展柜三级付费结构沿实际材质增加支架、灯光与短管，升级完成即提供同相机、同时间、同物件状态的免费前后对照。

### 同一星球昼夜与居民生活

240秒白天、60秒夜班沿用统一存档时钟。黄昏冷暖转换与仓库亮灯；夜间机器人沿球面追踪，飞船搜索照明，实际安保设备引导、隔离或承受冲击；清晨按真实损伤与资金焊补、结算并继续探索。事件关键接触提供同源观察窗，完整星球保持可见。

三次异常分别采用箱形、扑翼与纸影姿态，处理过程有识别、折叠或引导、入匣与原仓库交接。飞船、手位、容器、角色与门洞共用真实坐标和环境光，基础与完善配置产生不同的受损、维修和结果。

三位已发现居民使用独立栖台与日夜作息，白天觅食、搬运、抖动或巡飞，黄昏归巢，夜晚休息，清晨恢复。未发现居民不会出现在玩家可选目标或详情中。

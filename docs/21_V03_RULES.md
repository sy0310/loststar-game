# V0.3 首星样板：自主安保、真实损伤与零件用途

依据 [最新 Review 5754645811](https://github.com/sy0310/loststar-game/pull/2#pullrequestreview-5754645811) 及用户本轮明确确认，直接实现小切片；上一条Review中“先等确认”的条件已由用户本轮指示满足。不清存档，不做第二星，不正式发行。

| 方案 | 选择价值 | 制作/体验成本 | 结论 |
|---|---|---|---|
| 纯夜间随机事件 | 很少配置价值 | 最低，但过程和结果难关联 | 不采用 |
| 机器人＋飞船＋基地设施 | 设备影响真实核验窗口，维修与建设有取舍 | 复用原球体、事件时间轴、三位同类纸影 | 采用 |
| 传统塔防 | 更多实时布阵/点杀 | 需地图、炮塔、多波敌人，偏离放置探索 | 不采用 |

白天4分钟探索 → 黄昏亮灯 → 夜晚1分钟：咔哒核对/拦截、LR–01轨道警戒、警戒光束引导减速、隔离门短时阻拦 → 抵站纸影每位造成6点设施损伤 → 清晨维修、继续探索。只有一种纸影、两个设施位，一种零件货币。奇物留在收藏柜，研究可从已发现奇物取得灵感，不用本体攻击。

完整度0–100；未修时探索速度为80%＋完整度×0.2%，最低80%，绝不停止。每点维修选定3零件，修复工位两级依次降为2/1零件；只为真实修好的整点扣费，余额不足部分修、不借债，不失去永久收藏或设备。自动维修默认开，仅白天/清晨执行，允许关闭和手动维修。

自动维修使用一个**收入支出限额**：每份真实收入最多预留30%作为可用维护额度，上限300零件；这只是自动支出的上限，不是新增货币、预扣款或固定税。无损伤绝不扣费。关闭后不自动花钱，手动维修按实际余额与缺损执行。既有大额资金不重置；旧guard-0/1等级、原成本与上限原样转换为警戒灯/隔离门。

离线收入、损伤和付费维护只处理原货舱有效时长。超时进入护站模式，不再累加损伤/账单，世界昼夜继续。有效区间按真实收入事件、抵站、清晨和计划结束分段，线上/离线共用；退款/刷新/多标签不再支付已完成的维修。维护限额按已赚收入累计，最多300结余，不因反复切页获得新限额。

零件只保留三种用途：①真实设施维修；②有上限的永久工程（原设备/展柜/设施、安保设备、修复工位）；③自愿、固定预算、不会自动续费的定向调查/科研。计划选定90/1200/4800零件、5/15/30分钟，实际提高探索/地表采样10%/25%/40%，结束带回下一份本地分类发现或有具体藏品来源的观察记事；无新星假入口、无奖励循环刷钱。高预算科研需已发现奇物，藏品不消耗。

先用实际引擎模拟120/5000/27049/50000余额，0/15/30/60/120分钟及8/24小时；基础/升级、自动开关、无损/轻损/重损、积累/建设/科研全部对照。最终费用及第一小时是否正收益以真实模拟表为准，而非直接采用Review演示数值。

职责：地面咔哒读取封条 → 警戒灯延长可核对时间 → 隔离门争取停顿 → 飞船提供轨道照明；漏过者撞坏仓库护板 → 清晨修复焊接与完整度回升。沿用同一远征，不新增战斗页。


实际模拟已完成72组：无负余额、无超过收入30%的维修支出，基础安保新手首小时毛收入2160、维修216、净增1944。详见 `artifacts/v03/economy.md` / CSV / JSON。安保足够强时当前三位纸影可全拦截，零损伤就零费用；修复工位与强化安保是不同的可选回本路径，不要求所有设施买满。

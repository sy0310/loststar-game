# 退件平原动态样板 / 待用户视觉审核

## 方案

采用 Canvas 2D 分层 2.5D。使用原创重制的透明球体、机器人、飞船、仓库、拆封鼠及独立扫描/喷焰/拾取/旗帜层。场景只有少量可排序实体，当前没有引入 Pixi/Phaser 的必要；主包约 29 KB。未制作或测试真正 3D，不提供虚构的 3D 性能对比。

球体不晃动、不旋转整张拼版。飞船先画背轨，再画球体与地表实体，最后画前轨飞船。地面实体按接触点 Y 排序；机器人走仓库后方时，仓库真实覆盖其像素。角色路线限于可见球面，不做全向寻路。

## 与概念图的差异

| 项目 | 原概念图 | 实际运行时 | 复审重点 |
| --- | --- | --- | --- |
| 球体 | 带 UI 的整张参考，底部近似切面 | 独立闭合圆润地形层，完整紫红阴影与青色轮廓光 | 是否达到球体体积与材质要求 |
| 场景构图 | 高密度箱堆和巨大建筑 | 减少前景箱堆，仓库独立置于中央偏左，留出行动路径 | 建筑比例及清爽程度是否合适 |
| 机器人 | 静态概念形象/参考动作 | 上身与双腿切片驱动走路，扫描、拾取、携带返回、卸货 | 尚非完整手绘朝向帧；跨遮挡时可见性待复审 |
| 飞船 | 参考 MP4 有遮挡问题 | 独立精灵、前后轨道、尺寸变化、喷焰与朝向变化 | 球背全遮挡、球前盖住地表，轨道固定不碰 HUD |
| 生物 | 生态拼版 | 一只拆封鼠，细微姿态与拆箱纸屑循环 | 逐动作帧与更多居民后续制作 |
| UI | 装饰较重、部分参考文字不准确 | 中文重排、细边框、暖金操作/青色状态、持续挂机日志 | 阅读性与风格仍需用户确认 |
| 基地 | 已认可的大构图 | 保留紫蓝旧基地、暖灯与收藏柜，重新制作空展柜背景，按收集叠加藏品 | 新构图并不自动视为已获认可 |

收据、胶带、套娃包裹与事件信封另有独立像素图标，用于图鉴详情与基地展柜。源 PNG、内置 image_gen 完整提示词、导出脚本与程序动画源保留在 [assets](../assets/README.md)。没有从概念拼版硬抠角色；也没有手工 Aseprite 分层工程，当前透明原始 PNG 与动画代码是可修改源。

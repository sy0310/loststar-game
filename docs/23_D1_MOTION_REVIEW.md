### 夜间动作与原场景融合

- 原管道旁的事件点移到机器人原生左向扫描姿势可触达的位置。纸影的翼片、脚片围绕实际折点收拢，进入约37.18×20逻辑像素的透明内窗。

- 携行保持实心原角色姿势。接收使用原仓库立面门洞，进入部分由真实洞口裁切，外露部分位于机器人与门框的正确层级，随后关闸。

主线程实际退回过破旧化收据、内窗过窄的匣体、整张纸的偏移轮廓影、粗青色机械块、独立灰色假门框、双姿势透明重叠和几何长袖杆。最终候选经过真实墙钟DEV连续帧表复审，再从干净生产构建重新采集。

## 两份样板

### 原完整球体上的 30 秒邮路处置

| 时间 | 实际动作 |
| --- | --- |
| 0–4 秒 | 箱堆/管道旁纸影显形；原分拣站顶灯报警 |
| 4–10 秒 | 咔哒沿原可见球面邮路绕过仓库，前往事件点 |
| 10–15 秒 | 机器人与纸影保持可辨距离，扫描环、角标和细进度条核验 |
| 15–20 秒 | 纸影连续向手位折叠，进入独立透明收容匣 |
| 20–26 秒 | 咔哒携匣跨区域返回；飞船前轨暖光锥跟随事件点 |
| 26–30 秒 | 原仓库收件口开闸接收、关闸，咔哒回到站前，显示巡守完成 |

飞船沿用已获手机反馈正常的四向精灵、喷口、尾焰和完整前后轨道。后轨不穿球显示探照光；纸影参与同一世界深度排序。两个设施分别承担标记与收件隔离，没有沿屏幕底部排列炮台。

### 收据柜同镜头 Lv0–3

| 等级 | 结构与真实动态 |
| --- | --- |
| Lv0 | 原免费玻璃罩与普通底座；收据轻摆 |

## 美术与独立复审

素材由美术子智能体用内置 image_gen 制作原创透明件，原 PNG、完整提示词、返修记录、实测 alpha/足点/内腔和最近邻 WebP 导出均保留在 [D1 源目录](../assets/src/generated/d1/) 与 [运行时注册数据](../assets/runtime/d1/registration.json)。没有从概念拼版截取生产角色，也没有手工 Aseprite 工程。

主线程复审退回过窄内窗、非空白面板、挤占收据的机械、原型黑底铭牌、遮机器人脸的长标签，以及像弹道的细直搜照线。最终候选以真实运行的同镜头四档和连续动画为证据，不把静态注册审计图当作游戏截图。
